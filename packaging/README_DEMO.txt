Local TRPG（デモ版） — 起動方法

1. LocalTRPG.exe を起動すると、ブラウザで http://127.0.0.1:8000/ が開きます。
   API キーの設定は不要です（GM の応答はデモ用の中継サーバー経由で生成されます）。
2. 黒いウィンドウ（サーバー）を閉じるとゲームも終了します。

デモ用の中継サーバーには 1 分あたり・1 日あたりの利用上限があります。
「GMとの通信に失敗しました」と表示された場合は、少し待ってから再度お試しください。
自分の Gemini API キーで遊ぶ場合は、local_config.json の base_url の行を削除し、
"api_keys": ["自分のキー"] を書き加えてください。

セーブデータは saves フォルダ、ログは debug フォルダに保存されます。
