# 033 リーゼ调参记录

只变动リーゼ的回复比例与伤害骰。按 spec 第 6 节，在三场古戦場平均 HP 损失降低至少 30%、骑士战至少 +10pp 的前提下，限制城外胜率不超过现有最强同行者 +3pp。伤害条件、HP 阈值、元素、目标优先级均保持不变。

初值 20%／2d6 的完整 N=500 结果保存在 [initial.json](balance-2026-10-17-liese-initial.json)。四职业古戦場平均损失降低 40.9%～54.2%，骑士战提升 11.6～29.4pp；城外有 6 组越过上限，最高 +8.0pp。因此没有直接保留初值。

第一轮在古戦場三场及三个越界场景（`goblin_fort_fourth`、`valley_ledge`、`xanxus_phantom_battle`）进行筛选。以下“最低降幅”是四职业中最低的三场平均 HP 损失降幅，“城外最大超出”只指上述三个城外场景。

|回复／伤害|候选 N|最低降幅|骑士最低提升|城外最大超出|
|---|---:|---:|---:|---:|
|20%／2d5|200|38.7%|11.6pp|8.0pp|
|20%／2d4|200|34.9%|11.6pp|4.0pp|
|25%／2d4|200|35.3%|11.6pp|4.0pp|
|15%／2d5|200|37.4%|11.6pp|8.0pp|
|10%／2d6|200|39.7%|11.6pp|8.8pp|
|20%／1d10|200|37.9%|11.6pp|8.3pp|

这些筛选值使用初值评测保存的 N=500 无同行者／其他同行者对照，候选只取同种子序列的前 200 次，因此只用于选择复核方向，不作为最终验收结论。原始数据：[search.json](balance-2026-10-17-liese-search.json)。

第二轮将候选样本量也提高到 N=500，并向更低伤害延伸：

|回复／伤害|候选 N|最低降幅|骑士最低提升|城外最大超出|
|---|---:|---:|---:|---:|
|20%／2d4|500|34.4%|11.6pp|3.2pp|
|25%／2d3|500|34.8%|11.6pp|1.4pp|
|20%／3d2|500|33.5%|11.6pp|3.6pp|

采用 **25%／2d3**，因为这是本次复核中同时通过两类约束的参数。没有放宽 +3pp 上限来接受 3.2pp，也没有调整敌人或其他同行者。两份剧本及同行者说明文中的数值同步更新，说明文其他文字保持定稿。原始数据：[confirm.json](balance-2026-10-17-liese-confirm.json)。

最终采用参数重新执行古戦場三场和城外全部 26 场、四职业、全部同行者对照，结果与明确的未达项见 [最终报告](balance-2026-10-17-liese.md)。经验胜率用于本次固定策略验收，不代表所有玩家策略或连续路线都已得到证明。

## 复现

```powershell
python -m scripts.balance.liese --search --n 200 --output eval/reports/balance-2026-10-17-liese-search
python -m scripts.balance.liese --search --n 500 --variant 2d4:0.2 --variant 2d3:0.25 --variant 3d2:0.2 --output eval/reports/balance-2026-10-17-liese-confirm
python -m scripts.balance.liese --n 500
```

筛选命令只在内存中的剧本副本上变更参数，不写回剧本。
