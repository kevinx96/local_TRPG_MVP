## 3. 主要发现
1. **由引擎持有状态，注入就污染不了状态**：所有模型、所有变体的 S4 都为 0，主张已经成立。
2. **严格契约下，本地 3B–8B 模型完全不可用**：它们不守"按 kind 留空字段"的规则，InvalidPlan 接近 100%。宽松解析能把格式救回来，但 conflict 接近 100%，说明错误是语义上的，不只是格式。
3. **约束解码把格式错误转成了语义错误**：判别联合 schema 在 llama.cpp 上可以用，qwen 系模型准确率升到 33–36%，S3 却升到 15–21%：被强制给出合法结构时，它们倾向于选有代价的操作。日语特化的 elyza 是例外，S3 只有 1.5%。
4. **同一个 schema 在不同 API 上效果相反**：Gemini 的约束解码处理不了 `anyOf` + `const`/`enum` 结构，llama.cpp 可以。"schema 越严越好"并不成立。
5. **三句防误触发规则**以 +9% 输入 token 的代价，让 Gemini 的 S3 在 dev 上降了 83%，在 test 上减半（样本小，未做显著性检验）。

## 4. 战斗数值（`eval/reports/balance-2026-10-11-pass4.md`）
