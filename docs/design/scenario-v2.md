# 剧本设计 v2：白竜ドラコ（设计负责人，2026-10-12）

## 0. 原则
1. **条条道路通向胜利**：每个推进剧情的关键道具或情报，至少要有 **3 个来源**，覆盖不同的玩法：购买、支线或探索、战斗、对话或自由输入。错过一个来源，后面一定还有别的办法拿到，只是更贵、更难或绕远路。这是博德之门 3 的做法。
2. **自由输入也算一条路**：关键地点都要声明可以观察或调查的对象（`objects`），让玩家用自己的话也能找到线索。线索只能由引擎发放，模型不能宣称"已经发现"。
3. **合理优先**：发放线索要有剧情上的理由（谁、为什么、在哪）。不能为了凑来源，把关键道具塞进毫无关系的地方。
4. **不惩罚错过**：没有找到隐藏真相的玩家，照样能打到通常结局。隐藏 Boss 只是额外的真结局。

## 1. 真相（世界观设定，不直接告诉玩家）
- 很久以前，元素、人类、竜三方订立了「三界の盟約」：互不侵犯，竜守护山岭，人类治理平原。
- 将军ドラコ的真身是**白竜ヴァイス**。白竜一族在盟约下镇守北方雪岭，但ヴァイス不满"竜屈居于人类之下"，打算借刀杀人：
  1. 他化身人类，花了几十年爬上将军之位，取得国王的信任（国王对"邪竜复活"深感自责，正是因为当年是他听从ドラコ的建议，派兵进入竜の谷"勘察"，激怒了イグニス）。
  2. 他把霜之力注入イグニス的伤口，让红竜陷入疯狂，四处纵火。**燃烧的村子里那片不自然的结冰**，就是他暗中出手留下的痕迹；氷の精霊和氷霜の巨狼也是他力量的残渣。
  3. 他故意建议勇者用"冰"去对付イグニス，等人类杀死最后一头红竜，盟约就失去平衡，他再以"救国将军"的身份接管王国，并恢复白竜对人类的统治。
- Xanxus 是另一股势力：他想得到イグニス的火种，和ドラコ互相利用、互相提防。ワーロック说的"各方各怀心思"指的就是这件事。
- **主题**：竜和人都不是天生的敌人，真正的敌人是背弃盟约的人。

## 6. イグニス浄化ルート（2026-10-12 追加）

### 6.1 设计思路
イグニス的疯狂来自白竜打进伤口的"诅咒之霜"。知道这一点、并且手上有圣属性手段的玩家，可以在战斗中**不杀它，而是净化它**。这条路线的回报：
- 证据由イグニス亲手交出，揭发一定成立；
- 第5章的白竜二阶段，イグニス会赶来助战；
- 有专属的最佳结局。
没有走这条路线的玩家，照样可以打到原来的所有结局。

### 6.2 条件（多来源）
- **知道"霜是诅咒"**（满足任意一条）：`frost_trace_seen`、`noticed_general_frost`、`heard_treaty_lore`、持有白い竜鱗
- **有净化手段**（满足任意一条）：持有聖水；职业为僧侣（用 MP 6 代替聖水）
- **时机**：イグニス的 HP ≤ 40%（要先把它打虚弱）

三个条件同时满足时，イグニス战的战斗行动里出现一个特殊行动（其他时候不显示）：
- 一般职业：`purify_ignis_holy_water`「凍てついた古傷に聖水を注ぐ」（消耗聖水 ×1）
- 僧侣：`purify_ignis_prayer`「凍てついた古傷を聖なる光で清める」（消耗 MP 6；僧侣持有聖水时，两个都显示）
- 效果：战斗以 `purified` 结果结束（不算击败、没有击杀奖励、不发紅竜の炎核），设置 flag `ignis_purified`，`current_location: ignis_purified`

### 6.4 第5章的变化
- **白竜二阶段的援军**：持有 `ignis_ally` 时，进入二阶段的变身文之后追加一段：
