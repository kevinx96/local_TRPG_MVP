## 1. 世界结构
- 森 → 麓の村（主线，现有）／霧の古戦場（031）／**封印の洞窟の地下水路 → オークスドーン**（新）。
- オークスドーン → 霧の古戦場（城塞の街道，南）／**地鳴りの峡谷**（东，见第 5 节）。
- 三条第三章路线最终都汇入麓の村，再前往竜の谷。
- 古戦場和峡谷都是可选路线，最终汇入村子的主线（古戦場 → 村の裏手、峡谷 → 避難所の裏手）；草图里「戦→boss」的线按用户决定忽略。

## 2. 设定
- **オークスドーン**：古い樫の森の東端、峠の入口を塞ぐ石の城塞都市。**暁の守護団（ガーディアン）**が駐屯する。
- **暁の守護団**：古の盟約を「人の側から」見守ってきた騎士団。紋章は樫の葉と昇る太陽。十年前、将軍ドラコの竜の谷遠征命令を盟約を理由に拒んだため、王都からは冷遇されている。→ 真相线索的新来源，也解释了为什么王都的人不提这座砦。
- **守護団長ヴァルター**：白髪の老騎士。十年前の遠征を拒んだ当事者。
- **聖騎士リーゼ**：若い女性の聖騎士。古戦場から夜ごと聞こえる弔いの鐘を気にかけている。**同行者**。
- **鍛冶師ブリギッテ**：城塞工房の女鍛冶師。光の紋を刻む技を持つ（034 の装备线）。

## 4. 聖騎士リーゼ（同行者）
- 每回合开始：玩家 HP **低于 50%** →「癒しの祈り」回复最大 HP 的 20%；**50% 以上** →「聖光の一撃」对敌人造成 2d6 光（holy）属性伤害，**优先打不死系**，没有不死系时打 HP 最高的。
- 加入方式（三选一，BG3 式冗余）：出示守護団の推薦状／在祭坛奉上聖水／说服（1d20+wis，DC13，一次）。
- 不死系对光属性：古戦場的四种亡者、煤の亡霊、Xanxusの分身、亡霊主宰ゼボク统一为 **×1.5**，并加 `undead` 标签。
- 定位：古戦場的对策同行者。这里ワーロック的回复失效，リーゼ则同时能回复、能高效打亡者。

## 5. 第三章新地图「地鳴りの峡谷」（用户已确认方向，2026-10-17）
**属性分工**：每个区域一种基调，对策同行者也各不相同。

| 区域 | 基调 | 对策 |
|---|---|---|
| ゴブリン砦 | 物理 | ロビン |
| 麓の村 | 火＋冰 | 火コウモリ竜／ミーナ |
| 霧の古戦場 | 不死（弱光） | 聖騎士リーゼ |
| **地鳴りの峡谷** | **土**（抗物理 ×0.6，弱水 ×1.5） | **水術士**（新同行者） |

- **地点**：オークスドーンの見張り台から东の峠へ。和古戦場一样是可选路线，**出口汇入主线**：峡谷を抜けると麓の村の避難所（`village`）の裏手に出る。用户确认可以忽略草图里「戦→boss」那条线，古戦場的出口保持现状。
- **剧情**：峠は一夜の落石で塞がれた。その夜、白い巨大な影が谷へ飛んでいくのが目撃されている（樫の葉亭の噂）。崩れた岩の断面には巨大な爪痕と溶けない霜が残っている → 白竜が守護団を竜の谷から切り離すために道を崩した（真结局线索）。
- **敌人**（全部土属性）：砂礫の甲虫（普通）、岩の巨人（精英）、石肌のトカゲ（普通），Boss「土喰らいの大ワーム」。
- **对策同行者「水術士」**：在オークスドーン的樫の葉亭招募。每回合「水刃」对敌人造成水属性伤害（优先打弱水的敌人）；每 3 回合「水の帳」让那一回合玩家受到的伤害减半。在峡谷以外，对火系敌人也有效，其他地方表现普通。
- **难度**：和村子、古戦場同一档。

**033 的文本随之修改**（033 完成后由设计负责人改）：樫の葉亭的噂、見張り台的描述、东の峠的不可选原因，都从「霜」改成「落石」。
