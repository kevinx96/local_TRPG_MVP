## 0. 通用约定

### 0.1 基准 B 与资源上限（估算）

B = 同等级下该职业普攻的期望伤害（计命中，不计抗性、不计敌人防御和闪避）。成长按第 5.2 节取中值：主属性每级 +2、副属性 +1；最大 HP 每级 +17.5% 基础值；MP / SP 上限每级 +12.5% 基础值（四舍五入）。勇者的 B 按初始武器 鉄の剣 计算（换成 氷鉄の大剣 后 B 会上升，而技能按 STR 缩放，技能 / B 的比值会下降，见第 8.5 节）。

| 职业（普攻） | Lv1 B | Lv3 B | Lv5 B | Lv7 B | HP Lv1/3/5/7 | MP Lv1/3/5/7 | SP Lv1/3/5/7 |
|---|---|---|---|---|---|---|---|
| 勇者（鉄の剣 1d8+str/3，90%） | 7.7 | 8.6 | 9.5 | 11.3 | 20/27/34/41 | 8/10/12/14 | 10/12/15/17 |
| 僧侶（聖なる杖 1d8+wis/4，88%） | 6.6 | 7.5 | 8.4 | 9.2 | 18/24/31/37 | 14/17/21/24 | 8/10/12/14 |
| 魔法使い（魔力弾 1d4+int/4，90%） | 5.9 | 6.8 | 7.7 | 8.6 | 12/16/20/25 | 20/25/30/35 | 6/7/9/10 |
| 盗賊（ダガー 1d6+dex/4，95%） | 7.1 | 8.1 | 9.0 | 10.0 | 14/19/24/29 | 6/7/9/10 | 14/17/21/24 |

上表的 HP / 资源值只用来换算本文的百分比。正式成长表由数值 spec 定，届时按同样的比例重算技能消耗。

### 0.2 记号

- **区间编号**（对应第 5.4 节）：
  - A1 普攻；A2 标准技能（1.4–1.8 B，消耗为资源上限的 15–25%）；A3 大招（2.5–3.5 B，消耗 40–60% 或冷却 ≥ 3）；A4 群体攻击（每个目标 0.7–1.0 B）；A5 属性倍率；A6 持续伤害（≤ 敌人最大 HP 5% / 回合，≤ 3 回合）。
  - R1 单次回复（20–35%）；R2 大回复（50–60%，消耗 ≥ 60%）；R3 技能回复单场总量（僧侶 ≤ 80%，其他职业 ≤ 30%）；R4 防御姿态（×0.5 / ×0.25）；R5 致死保留 1 HP（G3）。
  - C1 临时闪避（+10–15%，≤ 2 回合，总闪避 ≤ 40%）；C2 减益：敌人伤害（−20–30%，2–3 回合）；C3 眩晕（1 回合）；C4 打断蓄力；C5 被动（每个 ≤ +15%，4 个合计 ≤ +40%）。
- **冷却 cd N**：使用后接下来的 N 个回合不能使用。例如 cd 1 = 隔一回合才能再用。
- **持续 N 回合**：从施放的那个回合的敌方阶段算起，共覆盖 N 个敌方阶段。持续伤害从下一回合开始结算，共结算 N 次（与引擎 `_tick_enemy_statuses` 现有的「回合开始结算、`remaining_rounds` 减 1」时序一致）。
- **字段**：`字段名` 表示引擎已经支持；`★字段名` 表示需要工程新增，名称只是建议，最终以工程 spec 为准。
- 引擎的骰子公式只支持 `NdM`、`属性/N`、常数和加减，不支持乘法；倍率一律用 `damage_multiplier` 或新增的条件倍率字段表达。

### 0.3 既有 level_skills 的处理（建议）

原稿只写了 Lv3/5/7 的新主动，与现有 `level_skills` 占用同样的等级。建议：

| 现有 | 处理 |
|---|---|
| 勇者 渾身斬り・改（Lv3）、不屈の構え（Lv5） | 删除；渾身斬り 保持 Lv1 数值。不屈の構え 的去留影响第 5.5 节，见第 7 节 |
| 僧侶 聖なる裁き（Lv3） | 删除（由 贖罪の印 接替 Lv3） |
| 僧侶 大いなる癒し（Lv5） | 由 大いなる癒し・浄化 **替换**（`replaces: 大いなる癒し`） |
| 魔法使い 火球・改（Lv2，全体）、氷の矢・改（Lv5） | 删除；火球 / 氷の矢 回到 Lv1 版本并补回未实装效果（第 4.1 节） |
| 盗賊 影隠れ・改（Lv3）、急所突き・改（Lv5） | 删除；影隠れ / 急所突き 保持 Lv1 版本 |

### 0.4 被动二选一与叠加规则

- 在 Lv2 / 4 / 6 / 8 各做一次二选一，选择不可撤销。
- 原稿中「效果相同，如果已获得则叠加」的选项是**可叠加被动**，规则如下：
  1. 以前没有选过它：这次获得第 1 阶，名称不加后缀（例如 `敬虔なる心`）。
  2. 以前选过：阶数 +1，名称后缀依次显示 `+1`、`+2`（例如 `敬虔なる心+1`）。被动栏只显示一个条目，不重复列出。
  3. 每一阶的数值写在各职业的被动表里。阶数只取决于"已经选了几次"，与在哪一级选的无关。
  4. 选择界面里，可叠加选项要显示"选了之后的效果"（例如「敬虔なる心 → 敬虔なる心+1：回复 3% → 5%」）。界面不提示哪个选项更好（决定 17）。
- **价值评估**：可叠加被动每多一阶就多占一个被动栏位，所以按"每占一个栏位 ≤ +15%"来衡量。例如两阶合计允许到约 +30%。M12 的"同组价值差 ≤ 10%"要按玩家之前的选择分情况计算（之前选过 vs 没选过）。
- 原稿中有三处分组没有写等级，按 Lv2/4/6/8 的节奏推断：魔法使い 的 `万象の支配者` 组 → **Lv8（推断）**；盗賊 的 `見切り反撃` 组 → **Lv6（推断）**，`無明の暗殺者` 组 → **Lv8（推断）**。

### 2.3 敬虔なる心：规则例外与 M3 核算

- **例外（用户 2026-10-20 确认）**：第 5.4 节规定"不允许每回合固定回复类被动"，对 僧侶 的 敬虔なる心 单独放开。理由（用户原话摘要）：僧侶 输出低；当初 勇者 + 火コウモリ竜 强，主要是因为勇者本来就打得疼；normal 难度下敌人伤害会大幅上调，所以用数值控制，不用规则禁止。
- **例外只适用于这一个被动。** 同伴、道具和其他职业的"与伤害无关的固定回复"仍然禁止（B3：火コウモリ竜 的回复必须和造成的伤害挂钩）。
- **数值**（按最大 HP 的百分比结算；引擎累积小数部分，满 1 HP 才回复，避免低 HP 时取整成 0 或跳档）：

  | 阶数 | 每回合回复 | 对 Boss 威胁带宽（28–35% / 回合）的覆盖 S_被动 |
  |---|---|---|
  | 第 1 阶 | 3% | 0.09–0.11 |
  | 第 2 阶（+1） | 5% | 0.14–0.18 |
  | 第 3 阶（+2） | 7% | 0.20–0.25 |

- **M3 核算口径**：S = 每回合期望回复 ÷ 每回合期望受到的伤害。分子包括**所有**玩家侧回复：被动（敬虔なる心、福音）、技能（治癒の祈り、大いなる癒し・浄化）、道具和同伴。敬虔なる心 不占 R3 的 80% 技能回复额度，但**必须计入 S**。
  - **P0b**（到达 Ignis 时 Lv4，最多第 2 阶）：S_被动 ≤ 0.18。技能回复受 R3 限制（≤ 最大 HP 的 80%），按 Boss 战 10–14 回合摊开，每回合 ≤ 6–8%，S_技能 ≤ 0.20–0.29。合计 S ≤ 0.38–0.47，低于 M3 的 0.5。**威胁带宽取下限（28%）、战斗又很短时最紧**，验收时按 28% 带宽和实际回合数核算。
  - **P2**（Lv6，第 2 阶）：8 回合的 Boss 战累计回复约 40% 最大 HP，相当于不占行动的一次 大いなる癒し，有实际意义。P3 / Lv8 拿到第 3 阶时，约 56%。
  - 如果 P0b 的 S 超过 0.5，先调低第 2 阶的数值（5% → 4%），不动第 1 阶。
- 结算时机：回合结束 = 敌方阶段之后、下一回合开始的状态结算之前。HP 为 0 时不触发。

## 3. 魔法使い

### 3.1 基础元素法术

## 7. 第 5.5 节检查：Lv5 之前的应对手段

判定口径：所有职业都有零消耗的通用 防御（×0.5），**它不算数**，否则这条规则就没有意义了。下面"边缘"的意思是：手段是 ×0.5 防御再加一点额外效果，能把 30–40% 的 Boss 大招压到 ≤ 20%，但压不住 45% 的上限（×0.5 后为 22.5%）。"Lv5 之前"按 Lv1–4 解读（P0 到达 Ignis 时是 Lv4）。

| 职业 | Lv1–4 的手段 | 来自被动？（两个选项是否都满足） | 判定 |
|---|---|---|---|
| 勇者 | 神聖の庇護（×0.5 + 致死保留 1 HP，cd 1）；聖光の剣技（Lv3，攻击回合 ×0.75） | Lv2 两个选项都不是（重装の心得 按 G2 对百分比招式无效）；Lv4 只有 不沈の盾 一边是 | **边缘**。原来 Lv5 的 不屈の構え（×0.25）删掉之后，勇者没有"强化防御"了 |
| 僧侶 | 聖なる守護（×0.5 + 致死保留 1 HP，6 MP）；治癒の祈り 可以事后补血 | Lv2 / Lv4 的选项都不是 | **边缘**（和勇者一样） |
| 魔法使い | 无（只有通用防御） | 只有 Lv2 的 魔導の盾 一边是，而且它会被第一次攻击打掉，等不到预告大招 | **不满足** |
| 盗賊 | 影隠れ（×0.25，2 SP）；目潰し投げ（Lv3，命中 −30 / Boss −20，对百分比招式也有效，因为百分比招式可以被闪避）；基础闪避 12–15% | 不依赖被动 | **满足** |

建议（按优先级）：

1. **魔法使い（需用户确认）**：给 魔力凝縮（瞑想）追加"本回合受到的伤害 ×0.5"。这和"冥想 / 凝缩"的主题一致，有 3 SP 的消耗，而且是 Lv3 的固定主动，满足"不依赖被动"。备选：Lv1 就给一个 秘術 防御法术（会改动初始技能）。
2. **勇者 / 僧侶（设计负责人可定）**：先接受"边缘"。Boss 的预告大招在 normal 难度下按 30–40% 设计，45% 的上限只留给"需要配合抗性道具"的大招（例如 Ignis 的 炎の息 + 紅玉の護符）。这样 G2 的"P2 压到 ≤ 20%"可以成立。如果模拟显示勇者在 Lv4 前的精英战中失败率明显偏高，再考虑把 不屈の構え 作为第 6 个主动保留（这一步需要用户确认）。
3. 附带检查第 5.5 节第 3 条（应对火抗 / 冰弱点敌人的手段）：勇者靠 氷鉄の大剣；魔法使い 有 氷の矢；僧侶 和 盗賊 只能靠道具，B1 限制护符之后，要确认商店里冰属性道具的供给。

## 8. 冲突与风险

标记：**【需用户确认】** = 涉及原稿意图；**【设计负责人可定】** = 只是数值或约束手段。

### 8.1 勇者（4 条）

- **H1 追い打ちの剣 的"半威力追击"超出被动上限。** 如果按"半威力 = 普攻或技能伤害的一半"，普攻输出 +50%，远超 C5 的每个被动 +15%。建议把"半威力"解释为"**武器骰子部分的一半**，不含属性加值"（鉄の剣 → 1d4，约 +20%），每次行动最多 1 次。保留了"自动剑气追击"的意图。【设计负责人可定】，模拟后如果仍然超标，再降为 1d3。
- **H2 不沈の盾 让致死保护重新变得几乎免费（G3）。** 神聖の庇護 零消耗、cd 1、又不占行动，相当于隔一回合白拿一次 ×0.5 和致死保留，约等于 25% 减伤，并且不损失输出。建议在 不沈の盾 下把冷却改为 cd 2。原稿只说了"cd 仍存在"，没有给数值。【设计负责人可定】
- **H3 竜断ちの一太刀 对龙几乎无效。** B2 把 Ignis 的 physical 降到 0.25，白竜ヴァイス 的 physical 也是 0.25；"必中 + 无视防御"不影响抗性，所以对 Ignis 实际只有约 0.84 B，和"断龙"的名字相反。可选方案：(a) 对 `dragon` 标签目标，物理抗性按最低 0.75 计算；(b) 元素改为跟随所装备武器（装 氷鉄の大剣 时为 ice，对 Ignis 打弱点，期望约 6 B，必须用 ×1.35 以外的方式压回来）；(c) 维持现状，接受它主要对付非龙的高 HP 敌人。【需用户确认】
- **H4 原稿里有两个被动有可能成为"死选项"（M12）。** 重装の心得 对百分比招式无效（G2）；旅立ちの気概 的"先手"在现有引擎里没有意义（玩家本来就先行动），实际只剩必中和 SP。两者都只在杂兵 / 精英战中有价值。先保留，靠模拟里的遭遇矩阵检查。【设计负责人可定】

### 8.2 僧侶（6 条 + 1 条已决）

- **已决：敬虔なる心 每回合固定回复。** 例外（用户 2026-10-20 确认），数值和 M3 核算见第 2.3 节。不再列为冲突。
- **C1 セラフィムの福音 的"HP 上限翻倍"有歧义。** 只扩容的话，施放当回合没有收益，要靠后续回复填满；如果当前 HP 同时翻倍，等于一次 100% 的大回复，超出 R2（50–60%）和 R3。本稿默认只扩容；受伤回复设为每次 8%、每回合最多 2 次、每场施放 1 次，持续 3 回合。另外：福音期间上限变大，大いなる癒し・浄化 更难溢出，和 溢れる慈愛 / 聖なる余光 互相抵消，这是有意的取舍。【需用户确认】施放时当前 HP 是否提高、提高多少。
- **C2 Lv6 只有一个选项**（溢れる慈愛+1），没有第二个选项，二选一不成立，M12 也没法验收。【需用户确认】请补一个 Lv6 选项 B。
- **C3 不滅の聖域 等于零消耗的每回合回复。** 每回合 1 次免费的 治癒の祈り（约 30% 最大 HP），会让 R3 和 M3 完全失控，重现"无限拖延"。敬虔なる心 的例外不覆盖它。建议每场最多免费 3 次（或者每 2 回合 1 次）。Lv8 只出现在 Ignis 之后，影响范围有限。【需用户确认】
- **C4 苦行の悟り 按 1:1 抵扣时，相当于 MP 每回合 +1**（SP 每回合自然回复 1），回复预算接近翻倍。建议 2 SP = 1 MP，每次最多抵扣 50%。这还会和 贖罪の印（消耗 SP）抢资源，属于正常的取舍。【设计负责人可定】
- **C5 溢れる慈愛 把治疗变成攻击，并且和护盾重复计算。** 满血时施放 治癒の祈り，伤害约 0.9 B（Lv2），+1 后的 大いなる癒し 可以达到约 2.5 B，同时还得到护盾。原稿意图是"同时触发"，本稿保留，但用转化比例（0.75 / 1.25）、护盾上限（最大 HP 的 25%）和"被动回复不算溢出来源"来约束。【设计负责人可定】
- **C6 R3（僧侶技能回复单场 ≤ 80%）现在就已经超了**：Lv5 的 MP（21）够放 1 次 大いなる癒し（55%）加 2 次 治癒の祈り（各约 30%），合计约 115%。这不是原稿造成的，但 苦行の悟り、不滅の聖域、福音 都会让它更严重。需要在数值 spec 里调整 MP 上限或消耗。【设计负责人可定】
- 附：贖罪の印 的价值接近标准技能的上限（3 回合 2.4 B），和 毒 同时作用于 Boss 时会被 5% 截断，没有问题。不计入条数。

### 8.3 魔法使い（7 条）

- **M1 魔力循環 与第 5.4 节"MP 战斗中不自动回复"、"不允许每回合固定回复类被动"冲突，而且可以叠到 3 阶。** 那条规则主要针对 HP（M3），MP 回复不进入 S，但 魔法使い 的 MP 就是输出。保留"每回合回复"的意图，用单场累计上限约束（20% / 30% / 40%）。【设计负责人可定】
- **M2 魔導の盾 第 2 阶每 3 回合重获，减伤可能达到 30% 左右。** 用"每场最多重获 2 次 + 重获的护盾最多吸收 20%"来约束；它占两个栏位，所以按 ≤ +30% 衡量。【设计负责人可定】
- **M3 元素崩壊 的段数随卷轴数量增加，没有上限。** 学到 6 种就是 5 B，超出 A3。建议核心集合只做 4 种（火冰雷秘），并且规定最多 4 段、按弱点挑选，这样收集带来的是"覆盖面"而不是"伤害无限涨"。反过来，只有初始 2 种时只有 1.7 B，P0 的魔法使い 拿到的大招偏弱（有意为之，但要在 M12 里观察它会不会变成死技能）。【设计负责人可定】
- **M4 氷炎の双嵐 在条件下接近大招，但消耗只有标准技能的水平。** 对 Ignis（冰弱点 1.5–2.0），进入 ≤ 40% 的第二阶段后，冰段 ×2 再乘弱点倍率，单次约 3.5 B。这是一个零准备的技能，会威胁"魔法使い 莽夫 ≤ 15%"（M1）。用 MP 总量限制（30 MP 约 4 次），待 P0b 模拟验收。【设计负责人可定】
- **M5 Lv5 前没有应对百分比招式的手段（第 5.5 节不满足）。** 见第 7 节，建议给 魔力凝縮 追加本回合 ×0.5 减伤。【需用户确认】
- **M6 万象の支配者 让零消耗的普攻自动打弱点**，有触发 M6（支配动作占比）的风险。另外，引擎的 `weakness` 在目标没有弱点时会退回 physical，对 魔法使い 不合适，要改为退回 arcane。Lv8 只在 Ignis 之后出现，风险较小。【设计负责人可定】
- **M7 删掉 火球・改 后，魔法使い 失去了 Lv2 的群体攻击**（spec 007 为了砦的多敌人战斗特意提前过）。雷撃 卷轴能补上，但需要购买，P0 拿不到。可选做法：雷撃 改为 Lv1 初始法术，或者在砦之前保证能拿到。【设计负责人可定】
- 附（不计入条数）：魔法使い 的 B 偏低（魔力弾 很弱），基础法术本身已经在 1.8 B 左右，再加 魔導書 +3 约 2.3 B，处在 A2 的上沿。这是现有数据的问题，在数值 spec 里一并核算。

### 8.4 盗賊（5 条）

- **T1 見切り反撃 一回合内可以无限触发。** 多敌人战斗中，闪避 30% 再加 目潰し −30，每回合可能落空 2 次以上；影隠れ 生效时，敌人的每次命中也会触发。输出可能 +100% 以上。本稿保留"一回合内不限次数"，同时把单次伤害降为 `1d6`（不加 DEX），建议再加**每场 8 次**的上限。【需用户确认】
- **T2 神速 的额外行动等于在持续期间让输出翻倍**，第 5.4 节没有对应的类别。本稿按大招处理：持续 3 回合（含施放回合）、持续期间不能重放、结束后 cd 3、双资源消耗，净多出约 2 次行动，约 2–3 B。另外，额外行动配合 暗器の達人 和 毒使いの技 会滚雪球，要在 P2 / P3 模拟里检查。【设计负责人可定】
- **T3 可叠加的毒和 A6 的"持续伤害不叠加"冲突。** 用户明确要求可叠加（包括敌人造成的可叠加中毒），所以改为：允许叠加，设层数上限，对精英和 Boss 的持续伤害合计截断在 5%。这样仍然满足 A6 的数值意图。【设计负责人可定】
- **T4 軽業の身のこなし 让闪避超过 G1 的基础上限 20%。** 本稿规定被动加成不受基础上限限制、计入总上限 40%。满级 盗賊 的闪避为 20% + 10% = 30%，再加上 目潰し，敌人对 盗賊 的实际命中率可能只有 40%。生存性要靠模拟确认，必要时把第 3 阶降到 +9%。【设计负责人可定】
- **T5 目潰し投げ 消耗 2 MP，占 MP 上限的 29%，略高于 A2 的 25%**；另外，对 Boss 持续施放可以让 Boss 伤害长期 −20%。目前靠 MP 总量限制（Lv3 时一场 3 次）。【设计负责人可定】
- 附（不计入条数）：Lv6 / Lv8 的分组是推断的（见第 0.4 节）。暗器の達人 配合 治療の巻物 是不占行动的 30 HP 回复，每场 1 次，属于道具回复，不计入 R3，但计入 M3。

### 8.5 通用（4 条，不按职业计数）

- **X1 既有 level_skills 的去留**（第 0.3 节）：删掉 不屈の構え 会削弱勇者的第 5.5 节应对手段；删掉 火球・改 会削弱魔法使い的群体攻击。【设计负责人可定】，不屈の構え 是否保留取决于第 7 节的模拟结果。
- **X2 B 依赖武器。** 勇者换上 氷鉄の大剣 后 B 上升，按 STR 缩放的技能和 B 的比值会下降，技能回合占比（M12 ≥ 35%）可能不够。数值 spec 要按"P2 在 Ignis 时的实际装备"重新核算 B。
- **X3 引擎缺口很多**（第 0.5 节）。建议工程分两步做：先做冷却、双资源消耗、条件倍率、状态（第 6 节）、被动框架；再做护盾、最大 HP 修正、卷轴学习和动态 multi_elements。
- **X4 被动叠加让 M12 的"同组价值差 ≤ 10%"依赖玩家之前的选择**（之前选过 vs 没选过）。模拟要按路径穷举，不能只比较单个选项。

## 9. 待模拟验收的数值清单

X / N 的建议值：薙ぎ払い X = 75%；竜断ち 对龙 ×1.35；贖罪の印 N = 3；福音 N = 3（每次回复 8%）；魔力凝縮 X = 30%；元素共鳴 X = 15%；マナ・アーマー X = 25%；目潰し投げ N = 2（−30 / Boss −20）；神速 N = 3；剣聖の境地 X = 30%；敬虔なる心 3% / 5% / 7%；魔力循環 1 / 2 / 3 MP（单场上限 20% / 30% / 40%）；毒 每层 2（玩家施加）/ 1（敌人施加），上限 3 / 5。

## 用户决定（2026-10-20，覆盖上文的建议值和"需用户确认"项）

1. **セラフィムの福音**：发动时 HP 上限提高，同时**回复与提高量相等的 HP**（不是只扩容）。
2. **僧侶 Lv6 第二个选项**：光輪の加護（光轮加护）——每回合开始时，若自身 HP 高于 X%，自动对敌方降下一道圣光追击（holy）。X 和追击伤害按第 5.4 节被动的整体等效上限设定，待模拟验收；与「溢れる慈愛+1」构成二选一。
3. **見切り反撃**：**不设触发上限**（一回合内可以一直触发）。单次追击伤害按本文建议值，待模拟验收。
