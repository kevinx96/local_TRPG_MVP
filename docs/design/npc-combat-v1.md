# NPC 可攻击与守護の竜騎士

设计负责人，2026-10-19。对应 spec 041（F）。日文为定稿文本，照抄。

## 1. 原则
- 玩家可以对场景里的人物动手，世界会还手，并留下后果。
- **会影响主线的人物不能被杀**（第 2 节的「保護」）；其余都可以被杀。
- **孩子不会被杀**：サラ、リク被攻击时由守护者出手；守护者倒下后孩子逃走，效果和"失去这个人物"相同。
- 杀死或赶走**城镇人物**会留下「町の血」（flag `town_blood`），招来守護の竜騎士（第 6 节）。城镇：王都城下町（含宿屋、道具屋、魔法店、鍛冶屋、路地裏）、麓の村、城塞都市オークスドーン、凱旋の城下町。
- 攻击必须先经过引擎的二次确认（第 4 节），避免模型误判让玩家莫名其妙开战。

## 4. 攻击流程
1. 自由输入被解释为「攻撃」，对象是当前场所的人物 ID。
2. 引擎按分类处理：
   - **保護（阻止／すり抜け／汎用）**：直接显示固定叙述，不确认、不开战、不留后果。
   - **保護（反逆）**、**可杀**、**孩子**、**特殊**：先确认。
3. 确认：叙述「{名前}に武器を向けようとしている。本当に攻撃するか？」，只有两个选项：
   - 「{名前}を攻撃する」（风险：危険（戦闘））→ 引擎直接开战（含守护者），**不再调用模型**；战斗结束后按现有流程叙述一次。
   - 「やめておく」→「あなたは武器を下ろした。」，恢复原来的选项。
4. 反逆的人物确认后不开战，直接进入反逆エンド。

### 固定叙述
- ワーロック（阻止）：杖を振るより早く、見えない壁があなたの腕を押し戻した。ワーロックは本から目を上げもしない。「店の中では静かに頼むよ」
- ミーナ（魔法店）：見えない壁があなたの腕を押し戻した。ワーロックが静かに本を閉じる。「弟子に手を出すのはやめてもらおうか」
- 亡霊の兵士：刃は半透明の体をすり抜け、冷たい風だけが残った。亡霊の兵士は悲しげにあなたを見つめている。
- 汎用：今は、その相手に刃を向けるべき時ではない。
- 反逆エンド（ending `treason`，标题「反逆者」）：
  - 国王：剣を抜いた瞬間、将軍ドラコの刃が先にあなたの喉元へ届いていた。「陛下に刃を向けるとは。……愚かな」 視界が白く凍りつき、あなたの名は反逆者として記録された。
  - 将軍：踏み込んだはずの一歩より早く、白い刃があなたの胸を貫いていた。「剣聖に挑むには、早すぎたな」 王城の床に霜が広がり、あなたの名は反逆者として記録された。

### 倒下时的叙述（战斗结算之后的系统叙述）
- イアン：イアンは古い金槌を握ったまま、カウンターの陰に崩れ落ちた。
- ロビン：ロビンの弓が床に落ちた。「……あんたを、信じてたのに」
- サラ（逃走）：火コウモリ竜が床に落ちると、サラは悲鳴を上げて店の奥から逃げ出していった。道具屋には、もう誰もいない。
- 火コウモリ竜：小さな炎が消え、火コウモリ竜は動かなくなった。
- ローベルト：ローベルトは金槌を取り落とし、炉の前に崩れ落ちた。炉の火だけが、変わらず燃えている。
- 怪しい商人：黒いローブがしぼむように崩れ、中身は煙のように消えた。後には、毛の束と小さな袋だけが残っている。
- ガルド：陽気な行商人は、荷車にもたれるようにして動かなくなった。
- 村の長老：長老は杖を取り落とし、静かに目を閉じた。
- リク（逃走）：リクは泣きながら避難所の外へ駆けていった。
- 道具屋の店主：店主は帳簿を抱えたまま、棚の前に倒れ込んだ。
- 迷子のゴブリン：ゴブリンは小さく鳴いて、動かなくなった。
- ヴァルター：老騎士は剣を支えに膝をつき、そのまま倒れた。「守護団に……栄光を」
- リーゼ：リーゼの盾が石床に転がった。「光よ……この人を、お赦しください」
- 老司祭：老司祭は祈りの言葉を最後まで言えずに、祭壇の前に倒れた。
- ブリギッテ：ブリギッテは前掛けを血に染めて、金床の横に崩れ落ちた。
- エリオ：エリオの周りの水が、ただの水たまりになって床に広がった。
- ミーナ（洞窟）：ミーナは杖を握ったまま、湯けむりの中に倒れた。

## 5. 后果
- 倒下或逃走的人物从所有场所消失，与其相关的选项、委托、入队都不再出现。
- 之后有该人物登场的剧情场景，改用"此人不在"的写法或直接跳过，但**离开场景的选项必须保留**，不能卡死。工程逐一列出受影响场景，设计负责人补写替代文本。
- **商店**：店主倒下或逃走时商店关闭。玩家得到柜台里的东西：所有售价 ≥ 40G 的商品各 1 件、所有限量库存商品的全部库存，以及钱箱金币（道具屋 30G、鍛冶屋 40G、村の道具屋 20G、ガルド 50G（一次）、城塞工房 60G）。系统日志：「{店名}の品を手に入れた。」
- 尾声：有 `town_blood` 时追加一行：町の人々は、あの日の惨劇を忘れていない。英雄の名が語られるとき、そこには必ず血の影がつきまとった。

## 6. 守護の竜騎士
**人物**：竜騎士ガレス（Gareth），暁の守護団的竜騎士，骑着被人驯服的灰鳞飛竜ノクス（Nox）。和被诅咒的イグニス、伪装成人的ヴァイス形成对照：人与竜也可以并肩。他在城壁の見張り台巡视，惩罚伤害无辜的人。

**平时的对话**（`dragon_knight` 的对话选项「竜騎士と話す」，按次数轮换，无影响）：
1. 「ノクスは南風が好きでな。霧の古戦場から風が吹く日は、機嫌が悪い」
2. 「竜が人に懐くのは珍しいと言われる。だが、こいつは卵の時から俺の外套の中で育った」
3. 「見張りは退屈なくらいがちょうどいい。何も起きないのが一番だ」
4. 「人に飼われた竜がいるなら、人を憎む竜がいても不思議はない。……谷の紅竜も、何かあったのかもしれんな」

**有 `town_blood` 时**：平时的对话选项隐藏，换成「竜騎士に話しかける」（风险：危険（戦闘））。叙述后**强制开战**，不能逃跑：
> ガレスは槍を手に取ると、あなたの前に静かに立ちはだかった。背後で、灰色の飛竜が低く喉を鳴らす。「……血の匂いがする。町の者を手にかけたのは、お前だな」「守護団は民を守るためにある。ここで終わらせる」

**拦截**：有 `town_blood` 且没打倒过ガレス时，イグニス戦之后选「王城へ戻り、国王に報告する」（`ignis_last_breath` 和 `ignis_purified` 两处），不去王城，而是进入新节点「竜の谷・帰路」，直接开战，中间不能休息：
> 谷を抜けようとしたとき、頭上を大きな影が横切った。灰色の飛竜が岩棚に降り立ち、その背から竜騎士が槍を構える。「竜を討った英雄、か。だが町の者の血は、竜の血では洗い流せない」「ここで裁く。ノクス、行くぞ」

胜利后照常前往王城。在城塞已经打倒过ガレス（`dragon_knight_defeated`）的话不再拦截。直接攻击ガレス本人也进入这一战（没有 `town_blood` 也一样）。

**战斗**（用 `next_phase`，同ドラコ→ヴァイス 的写法）：
- 第一阶段「竜騎士ガレスと飛竜ノクス」（骑竜）：HP 150，防御 2，回避 6
  - 普通攻击「竜槍の突撃」1d10+6，命中 85，物理
  - 「灰風の息吹」1d12+6，命中 90，風
  - 「急降下」2d8+4，命中 70，物理
  - 抗性：物理 0.75、風 0、氷 1.5、雷 1.5
- 转换叙述：飛竜ノクスが翼を裂かれ、地に落ちた。ガレスは竜の背から飛び降り、その首を一度だけ撫でる。「……下がっていろ、ノクス」 その瞳が、竜と同じ金色に染まっていく。
- 第二阶段「竜騎士ガレス」（人形态，更强）：HP 100，防御 3，回避 10
  - 普通攻击「竜血の槍」1d10+9，命中 90，物理
  - 「穿竜突き」1d8+8，**防御无视**，命中 100
  - 「竜騎士の構え」防御
  - 抗性：物理 0.85、風 0.5
- 胜利：ガレスは槍を杖にして膝をついた。「民の血を……忘れるな」 飛竜が主をくわえ、灰色の空へ飛び去っていった。→ 30G、灰竜の鱗 ×1（戦利品，售价 30）。ガレス不死，之后不再出现。
- 败北：竜騎士の槍があなたを貫いた。「守護団の名において」 → 现有败北流程（区域重来）。
- **难度目标**：满资源（Lv5 检查点）时胜率介于イグニス戦和ドラコ戦（含ヴァイス）之间；同时报告"イグニス战后不休息直接打"的胜率。城塞里提前打用同一套数值（玩家选择了冒险）。

**美术**：
- `npc_dragon_knight.png`：立绘。中年竜騎士，灰银的竜鱗甲、暁の守護团的白外套（樫と太陽の紋章）、长枪，金色眼睛，沉稳。
- `enemy_dragon_knight_mounted.png`：骑在灰鳞飛竜ノクス背上的全身战斗图。
- `enemy_dragon_knight.png`：人形态战斗图，和立绘同一个人，摆出持枪架势，眼睛发出金光。
- 风格同 033 的 NPC 立绘（参考 `npc_walter.png`、`npc_robin.png`）。

## 7. 模型侧（prompt 措辞，归设计负责人）
- `operation` 增加 `attack`：在 PLAN_PROMPT 的 operation 列举里加「attack(人物への攻撃。target_id は npcs の ID)」。
- 新增规则：「冗談・脅し・仮定・否定の攻撃は attack にしない。攻撃の意思がはっきりしている時だけ attack。」
- 冻结 benchmark 的重放保持旧的 operation 列举和 prompt（同 060aefd 元素标签的做法），历史结果必须仍能 194/194 命中缓存。
