# 紅き邪竜イグニス 攻略书（2026-10-13 版）

基于 32 局自动试玩（4 职业 × 8 个种子，剧本版本 `2026-10-13-v029-design`，提交 922cb5c）整理。前半是给玩家的攻略，后半是路线是否雷同的分析。

## 0. 数据来源和局限
- 试玩脚本 `scripts/playtest/explore.py`：离线、无 LLM，只用剧本准备好的文本；每一步优先选还没试过的选项，推进章节的选项放到最后；战斗用平衡模拟的 `heuristic` 策略；战败后重来一次。
- 它**不进商店、不刻意休息、不会为 Boss 做准备**，所以死亡率明显高于真人玩家，不能当难度结论（难度看 `eval/reports/balance-*`）。它的价值在于：把每个地点的选项都尝试一遍，看看路线怎么分岔、哪里汇合、哪里会卡住。
- 同一种子的不同职业共用随机数，前几步的选择往往相同，所以同种子之间的相似度会偏高。

## 2. 主干路线（10 个通关局全部经过的地点）
地理上是一条线：**王城 → 城下町（五个设施）→ 闇の森 → 麓の村 → 竜の谷 → 王都に凱旋 → 凱旋の間**。分岔都在章节内部，出了这一章就汇合。

### 第 1 章 王都
- 必做：侍従から旅の支給品を受け取る（聖水 ×2）、国王に邪竜の詳しい話を聞く（冰是弱点）。
- 强烈推荐：**魔法店「パーティーへ招く」带上ワーロック**（理由见第 4 节）。「最近変わったことは？」接ミーナ的委托，同时降低洞窟封印的难度。
- 勇者专属：鍛冶屋「鍛冶師に剣を見せる → 鍛冶師の提案を受け入れる」，免费换到氷鉄の大剣。
- 其他职业的冰属性来源：魔法店 / 鍛冶屋买氷の護符，或在森里拿到氷の結晶后找ローベルト加工。
- 「浮かない顔をしているが？」接鍛冶師の形見（ハンマー在ゴブリン砦，归还后最终战有追击）。

### 第 2 章 闇の森
- 森の入口：スライム（必战）→ 迷い子の十字路。
- 十字路是第一个大分岔：
  - 「箱を取り戻す手伝いを引き受ける」→ ゴブリン砦（得到合言葉）。砦是**可选的高难地下城**，顶层ゴブリン王是全剧最常见的死亡点；入口可以「砦を出て十字路へ戻る」。
  - 「迷子のゴブリンを無視する」→ 他会偷袭，打倒后砦里只剩「箱を持ち帰る」。
  - 也可以从宿屋接ロビン的委托直接进砦（这 32 局里经这条路通关的为 0，见第 4 节）。
- 精霊の泉：休息会触发スライム三连战（スライム王），泉の奥の岩壁通往**封印の洞窟**（ミーナ、虹晶の欠片）。
- 狼の縄張り：戦う / 携帯食で誘導 / 潜行 / 見捨てる，四种都通关过。救下行商人ガルド，之后有他的店和情报。

### 第 3 章 炎上する麓の村
- 入口：「慎重に村へ近づく」（int 判定）或「炎の中へ踏み込む」（战斗），两种都通关过（5 / 7 局）。
- 燃える民家：梁を叩き壊す（str）/ 窓からよじ登る（dex）救出リク，或先を急ぐ（放弃）。
- **Xanxus の最後通告**是全剧最危险的抉择：
  - 「大人しく従う」：吞下火种，之后怕冰和水。
  - 「死んでも従わない」：**只有带着ワーロック时**他会出手相救；没带就直接是坏结局（4 局都死在这里）。
- 結氷した場所を探索する → 氷の精霊 → 氷霜の巨狼（掉白い竜鱗，真结局的关键证据）→ イアンの頼み。

### 第 4 章 竜の谷
- 入口：霧に紛れてやり過ごす / 煤の亡霊と戦う；溶岩の吊り橋：吊り橋を渡る / 岩棚の迂回路。都有人通关。
- イグニス战：带冰属性。満足条件时可以浄化（4 局浄化、6 局讨伐）。

### 第 5 章 王都に凱旋（真结局）
- 凱旋の間里的「将軍ドラコの正体を問いただす」需要证据：**白い竜鱗**，或者至少两条线索（将軍の吐息が凍っていた、イグニスの最期の言葉、古い盟約の話、ガルドの噂……）。
- 告发前尽量凑齐最终战的助力（每一项都会在战斗中出现一句台词）：
  | 助力 | 怎么拿 |
  |---|---|
  | 国王的近卫兵 | 「国王に内密の謁見を願い出る → 将軍への疑いを打ち明ける」得到国王的信任 |
  | ロビンが盗んだ首飾り（白竜 HP −5%） | ロビン入队 **并且** 打通ゴブリン砦 |
  | ミーナと師匠の結界（冰伤 −20%） | 完成ミーナ的委托 |
  | 霜断ちの刻印（追击） | 把刻印のハンマー还给ローベルト |
  | 霜封じの護符（凍てつく吐息 −30%） | 潜入将軍の屋敷，在书斋「小箱を開ける」 |
- 32 局里两次告发都败了：两局都只有国王的信任，都没有ミーナ和ローベルト的助力；一局拿到了护符，另一局连屋敷的书斋都没进。ロビン虽然入队，但没打通砦，首饰的效果没有触发。

## 4. 路线是否雷同
**结论：怎么走很分散，走到哪里很雷同；而且通关明显依赖一个选择（带ワーロック）。**

1. **选择分散**：两两比较通关局的选择集合，平均重合率 0.37（0.24–0.62）。每个分岔的各个选项基本都有人走通，例如狼的四种处理、村子的两种进入方式、Xanxus 的两种回应。
2. **地点雷同**：到访地点平均重合 0.65（0.46–0.95），所有通关局都经过同样的 23 个地点。五章是线性的，分岔在章节内汇合，这是短篇 TRPG 模组的常见结构，本身不算问题；但玩家二周目会觉得「换了做法，走的还是同一条路」。
3. **ワーロック依赖**（最需要处理）：
   | | 局数 | 通关 | 到达竜の谷 |
   |---|---:|---:|---:|
   | 带了ワーロック | 20 | 9 | 14 |
   | 没带 | 12 | 1 | 4 |
   原因有两个：他每两回合回复 15% HP，在后期很稳；更关键的是 **Xanxus 的「死んでも従わない」只有他能救**，没带他时这个选项就是直接死亡（4 / 12）。这违背了「每种选择都能导向胜利」的原则。
4. **真结局 0 / 32**：告发需要证据，最终战需要好几项助力，而这些分散在第 1–5 章的支线里。这个难度本身合理（真结局本来就该难），但目前没有任何提示告诉玩家这些支线会在最终战派上用场。
5. **ロビン路线**：ロビン入队的局里没有经她的委托进砦后通关的。砦对第 1 章的等级偏难，而她的路线是从宿屋**直接**进砦，跳过了森林前半段的成长。

## 5. 建议（待决定）
1. **Xanxus 拒绝分支**：没带ワーロック时不应该直接死亡。改成「重伤逃离」：被打倒后在避难所醒来，失去一部分金币，不吞火种；作为代价，之后竜の巣前的 Xanxus 改为敌对遭遇。带ロビン时可以改成她来救（她本来就是义贼）。
2. **同伴差异化**：给ロビン和火コウモリ竜各一个只有她 / 它能解决的场景，例如ロビン知道砦的裏口（已有「砦の裏口から森の出口へ抜ける」可以挂在她身上），火コウモリ竜能抵消村子的火势。目标：四种同伴组合的通关率差距不超过 15 个百分点。
3. **ロビン的委托**：接下后先到十字路（而不是直接进砦），让玩家先经过森林前半段，再决定进不进砦。
4. **真结局提示**：在第 5 章的王の私室里，让国王根据玩家缺少的助力给一句提示（例如「将軍の屋敷に何か手がかりが残っているやもしれぬ」），不直接写出清单。
5. **第二条地理分支（较大改动）**：要让二周目走的地方也不一样，可以考虑在第 2 章出口让玩家选择「麓の村」或「山越えの古道」中的一条，两条在竜の谷汇合。这个工作量大，建议在 1–4 做完、看过真人试玩之后再定。
