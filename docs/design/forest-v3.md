# 剧本 v3：闇の森的地图化、封印洞窟、NPC 支线（设计负责人，2026-10-12）

原则沿用 `scenario-v2.md` 第 0 节：每个关键物品至少 3 个来源；支线可以在城镇对话里接，也可以在路上通过选项、判定、偶遇触发，或者带着关键物品回城触发。日语正文**逐字使用**。

## 1. 森林的新结构

### 1.1 主线（必经，从入口到出口一条线）
```
[F1 森の入口] → [F2 迷い子の十字路] → [F3 精霊の泉] → [F4 狼の縄張り] → [F5 森の出口]
                     │                     │
                     └─ ゴブリン砦（任意）  └─ 封印の洞窟（任意，需要判定）
```
| 节点 | 现有地点 | 变化 |
|---|---|---|
| F1 森の入口 | `dark_forest_loc` | 不变（スライム：可以战斗、诱导、潜行） |
| F2 迷い子の十字路 | `lost_goblin_crossroads` | 「箱を取り戻す手伝いを引き受ける」后**不再直接传送进砦**，改为接取任务，并在十字路出现「ゴブリン砦へ向かう」；无视迷路哥布林时的战斗胜利后留在十字路，不再自动前进。新增「先へ進む」→ F3 |
| F3 精霊の泉 | `elf_spring` | 「休む」：全回复，但会引来史莱姆袭击（第一波 → 第二波 → スライム王，现有流程），打完回到 F3（不再直接去出口）。「休まず先へ進む」→ F4。新增「泉の奥の岩壁を調べる」→ 封印の洞窟入口 C0 |
| F4 狼の縄張り | `forest_wolves` | 由"进入就开战"改成**先遭遇**：森狼在追咬一名行商人（支线 3）。行动：战斗、用携帯食诱导、潜行通过（三种都用现有的自由行动 obstacle 机制，再给 2 个按钮）。胜利或通过后 → F5 |
| F5 森の出口 | `forest_exit` | 不变 |

- 史莱姆王的里程碑（Lv2）改为：通过 F4 时触发（不管有没有打史莱姆王）。flag 选择交给工程，原则是**主线上必定经过的地方**。
- 哥布林砦：入口在 F2。砦的最后（箱子的处理结束后）**回到 F2**；作为奖励，另外开放一条近路「砦の裏口から森の出口へ抜ける」→ F5。
- 封印の洞窟：入口在 F3，结束后回到 F3。

### 1.2 地图功能（数据与表现）
- 剧本新增顶层 `maps`。每张地图：`id`、`title`、`nodes`、`edges`。
  - node：`id`、`label`、`kind`（`start` / `battle` / `event` / `rest` / `boss` / `branch` / `exit` / `locked` / `treasure`）、`x`、`y`（0–100 的相对坐标）、`location_ids`（属于这个节点的地点，可以有多个，例如泉和史莱姆袭击的几波都属于 F3）、可选的 `submap`（这个节点本身是一张子地图，例如砦、洞窟）、可选的 `recommended`（推荐等级的显示文字）。
  - edge：`from`、`to`，可选的 `action_id`（点击地图节点时执行哪个动作）。
- 三张地图：`forest`（F1–F5 加上砦、洞窟两个入口节点）、`goblin_fort`、`sealed_cave`。
- **可见性**：去过的节点完整显示；和去过的节点相邻、但还没去过的，显示成"？"（看不到种类和名字）；其余隐藏。封印的入口被发现以后显示锁的图标，解开以后变成普通入口。
- **点击移动**：点相邻的节点时，如果有对应的 `action_id`、并且这个动作当前可以执行，就执行它；否则只显示节点的名字和说明。战斗中、结局后都不能点击。
- **界面**（风格沿用现有的深色 + 金色）：
  - 画面右上角、MENU 按钮旁边加一个「MAP」按钮，点开是全屏的地图窗口（和 SYSTEM MENU 同样的结构）。
  - 在森林、砦、洞窟里时，MENU 按钮下方常驻一个**小地图**（约 200×140px，`--panel` 半透明背景，`--line` 描边），只显示当前地图，当前节点用金色光圈标出，点击小地图就打开全屏地图。
  - 节点是圆形：去过的用 `--panel-3` 填充、`--gold` 描边；当前节点外加 `--gold-glow` 的脉动光圈；"？"节点虚线描边，用 `--muted` 显示问号。种类用简单的符号区分（⚔ 战斗、✦ 事件、☾ 休息、♛ Boss、⌂ 出口、🔒 封印、◆ 宝箱；表情符号显示效果不好的话，就改成 CSS 画的图标，汇报里说明）。
  - 连线：走过的用 `--gold-dim`，其余用 `--line`。
  - 全屏地图里，节点下方显示名字；鼠标悬停（触屏是点按）时显示 `recommended` 和一句说明。
  - 子地图节点（砦、洞窟）在森林地图上显示成一个带边框的方块。进入以后小地图切换成子地图，全屏地图左上角显示「闇の森 › ゴブリン砦」这样的路径，可以点回上一级。

## 2. 封印の洞窟（新，半线性，结构参照ゴブリン砦）

### 2.1 结构
```
C0 封印の岩壁 ─(判定)→ C1 熱気の回廊 → C2 分かれ道 ┬→ C3a 溶岩の小部屋（宝箱）──┐
                                                    └→ C3b 地底の温泉（休息/ミーナ）┴→ C4 水晶の回廊 → C5 虹晶樹の間 → 回到 F3
```

### 2.2 节点正文
**C0 `cave_seal`「泉の奥・封印の岩壁」**
- description：泉の裏手の岩壁に、七色に揺らめく魔法陣が刻まれている。陣の奥から、かすかに熱い風が吹き出している。
- 观察对象 `seal_glyphs`（魔法陣の文様）：1d20+int，DC12，成功 → flag `seal_pattern_known`，成功文：文様の一部が、精霊の泉の水面と同じ律動で明滅している。泉の力で解ける封印らしい。失败文：複雑な文様の意味は読み取れなかった。
- 动作（任意一个成功即可通过，flag `cave_seal_broken` → C1）：
  - `decode_seal`「魔法陣を解読する」｜1d20+int，DC15；持有 `seal_pattern_known` 或 `heard_seal_lore` 时 DC 降到 8
    - 成功：魔法陣の線を一本ずつなぞると、七色の光がほどけるように消えた。
    - 失败：SP -2，失败文：光が弾け、指先に痺れが走った。もう一度試すこともできる。
  - `pray_at_seal`「泉の精霊に祈る」｜1d20+wis，DC14
    - 成功：泉の水面が光り、その輝きが岩壁の魔法陣を静かに溶かしていった。
    - 失败：SP -2，失败文：泉は静まり返ったままだ。
  - `pour_holy_water_on_seal`「聖水を魔法陣に注ぐ」｜条件：持有聖水｜判定不要｜消耗聖水 ×1
    - 结果文：聖水が触れた瞬間、魔法陣は白い煙を上げて砕け散った。
  - `force_seal`「力ずくで岩壁を砕く」｜1d20+str，DC17｜失败时 HP -4
    - 成功：渾身の一撃で魔法陣ごと岩壁がひび割れ、通路が口を開けた。
    - 失败：魔法陣に弾き返され、体が岩に叩きつけられた。
  - `leave_seal`「泉へ戻る」→ F3
- `heard_seal_lore` 的来源：魔法店「泉の封印について尋ねる」（新子动作，结果文：「精霊の泉の裏に古い封印がある。泉と同じ律動を読めば、解くのは難しくない」）；ミーナの依頼（见支线 1）。

**C1 `cave_heat_corridor`「熱気の回廊」**
- description：岩肌が赤く光り、足元から熱気が立ち上る。岩陰で、溶岩をまとったトカゲが舌を鳴らしている。
- 敌人：熱岩トカゲ ×2（新）
- 动作：战斗；「岩陰を伝って抜ける」（1d20+dex，DC13，成功 → C2，失败 → 开战）
- 胜利 → C2

**C2 `cave_fork`「分かれ道」**
- description：通路が二つに分かれている。左からは溶岩の唸り、右からは水の滴る音と、かすかな人の声が聞こえる。
- 动作：「左の通路へ進む」→ C3a，「右の通路へ進む」→ C3b

**C3a `cave_lava_room`「溶岩の小部屋」**
- description：溶岩溜まりの縁に、古い宝箱が置かれている。宝箱の前で、小さな炎の精がいくつも踊っている。
- 敌人：炎のウィスプ ×3（新）
- 胜利后：宝箱「宝箱を開ける」→ 火球術の巻物 ×2、紅玉の護符（新物品，见 2.4）。结果文：箱の中には、熱を帯びた巻物と赤い宝石の護符が収められていた。
- 动作：「分かれ道へ戻る」→ C2；「奥へ進む」→ C4

**C3b `cave_hot_spring`「地底の温泉」**
- description：湯気の立ち込める小さな温泉がある。岩の隙間に、ローブ姿の少女が膝を抱えて座り込んでいる。
- 动作：
  - `rest_hot_spring`「温泉で休む」｜判定不要｜once｜HP/MP/SP 回复最大值的 50%。结果文：熱い湯に浸かると、疲れがじんわりと溶けていく。
  - 支线 1（ミーナ）的相关动作，见第 3 节
  - 「分かれ道へ戻る」→ C2；「奥へ進む」→ C4

**C4 `cave_crystal_corridor`「水晶の回廊」**
- description：壁一面に、赤・青・緑の水晶が生えている。足音が響くたび、水晶が震え、形を変えて動き出した。
- 敌人：紅晶ゴーレム ×1、蒼晶の蝶 ×2、翠晶の蜘蛛 ×1（新）
- 动作：战斗；「水晶の共鳴が収まるまで息を潜める」（1d20+wis，DC15，成功 → C5，失败 → 开战，并且敌人先手）
- 胜利 → C5

**C5 `cave_prism_tree`「虹晶樹の間」**
- description：洞窟の最奥に、七色の水晶でできた大樹がそびえている。枝の一本一本が脈打ち、根元には砕けた魔物たちの水晶が積み重なっている。
- 敌人：虹晶樹（Boss，新）
- 胜利：获得 `prism_shard`（虹晶の欠片）×1；结果文：大樹が砕け散ると、その芯から掌ほどの欠片が転がり出た。光にかざすと、色が絶えず移ろっている。→ 出现「泉へ戻る」→ F3
- 败北：HP 1，回到 F3（不算 game over，可选内容不让玩家永久失败）。败北文：水晶の枝に打ち据えられ、気がつくと泉のほとりに倒れていた。

## 3. NPC 支线（新增 4 条）
每条都写进任务日志（`quests`，格式和 012 一样）。

### 支线 1：「見習い魔法使いミーナ」（洞窟里的偶遇 + 回城触发）
- 新 NPC `mina`：見習い魔法使いミーナ｜魔法店の弟子。好奇心が強く、師匠の言いつけを破って封印の洞窟に入り込んだ。
- **开始方式**（任意一个）：
  - a. 魔法店「最近変わったことは？」（新子动作）→ 结果文：「弟子のミーナが戻らない。泉の封印の話をした翌日からだ……」，flag `mina_missing_heard`，**同时**获得 `heard_seal_lore`
  - b. 在 C3b 直接遇到她
  - c. 在 F3 观察对象 `small_footprints`（泉のほとりの小さな足跡）：1d20+wis DC10 → 成功文：小さな足跡が、泉の裏の岩壁へと続いている。flag `mina_tracks_found`
- C3b 的动作：
  - `talk_mina`「少女に話しかける」→ 结果文：「た、助けて……！封印を抜けたら戻れなくなっちゃって。奥の大きな水晶の木が怖くて動けないの」，flag `met_mina`
  - `escort_mina`「ミーナを連れて行く」｜条件：`met_mina`｜→ 同伴 `mina`（数据新增；每 2 回合对随机敌人造成 1d6 的冰属性伤害，数值由工程定），flag `mina_rescued`
  - `leave_mina_wait`「ここで待つよう伝える」→ 打倒虹晶樹后再回 C3b 接她时，也算 `mina_rescued`
- **完成**：带着 `mina_rescued` 回到魔法店 → 新动作 `report_mina_safe`「ミーナを無事に連れ帰ったと伝える」，结果文：「……世話をかけたな。礼を言う」，奖励 MP回復薬 ×2、flag `mina_quest_done`；同伴解除。此后由ミーナ负责虹晶武器的加工（2.5）。
- 任务：「見習い魔法使いミーナ」｜描述：魔法店の弟子ミーナが、封印の洞窟から戻らないらしい。｜start：`mina_missing_heard` / `met_mina` / `mina_tracks_found` 中任一｜阶段：「封印の洞窟でミーナを探す」（done `met_mina`）→「ミーナを連れ帰る」（done `mina_rescued`）→「魔法店に報告する」｜complete `mina_quest_done`

### 支线 2：「サラの薬づくり」（素材收集，可以先拿到物品再接任务）
- サラの道具屋新增子动作 `ask_sarah_request`「何か困っていることはある？」→ 结果文：「お母さんの薬を作りたいんだけど、光苔が足りないの。森の暗いところに生えてるんだって」，flag `sarah_moss_request`
- **光苔的来源**：F3 观察对象 `glowing_moss_patch`（岩陰で光る苔）：判定不要，once；C1 胜利后的战斗奖励；C3b 温泉的观察对象 `moss_on_wall`：判定不要，once。观察的成功文统一为：岩陰に、淡く光る苔が生えていた。少し摘み取っておこう。
- **交付**：在サラの店持有光苔 ×1 以上时，出现 `give_moss_to_sarah`「光苔を渡す」（不需要先接任务：没接任务时直接交付也可以，结果文相同）→ 结果文：「わあ、ありがとう！これでお母さんの薬が作れる！お礼に、これからはずっと安くしてあげるね」，flag `sarah_moss_done`，消耗光苔 ×1。效果：サラの店全部商品 8 折（引擎需要"店铺折扣 flag"），并赠送治療の巻物 ×1。
- 任务：「サラの薬づくり」｜描述：サラは、母親の薬に使う光苔を探している。｜start `sarah_moss_request`｜complete `sarah_moss_done`

### 支线 3：「行商人ガルド」（路上偶遇，结果影响后续）
- 新 NPC `gald`：行商人ガルド｜各地を巡る陽気な行商人。森で狼の群れに追われていた。
- F4 的描述改为：森狼の群れが、荷車を背にした行商人を追い詰めている。男はこちらに気づき、必死に手を振った。

## 4. 数值目标
- 封印の洞窟属于可选的高难内容，推荐 Lv2（地图上显示「推奨 Lv2」）：
  - C1、C3a：elite；C4：elite（多敌人）；C5 虹晶樹：boss。
  - heuristic 策略下，**Lv2 的胜率**按各自的类别取目标（elite [0.75, 0.90]，boss [0.60, 0.75]）；**Lv1 硬闯时**，虹晶樹的胜率 < 0.35（太早进去会很吃力，这是有意的）。
- 虹晶武器：装备后，最终 Boss イグニス的胜率提高 10–20 个百分点（和冰之护符同一档）。
- 支线奖励（折扣、鎧、药水）不要让主线的连续通关率超过目标上限 0.80；超过时，优先削减奖励。
