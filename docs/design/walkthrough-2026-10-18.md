# 紅き邪竜イグニス 攻略书（2026-10-18 版）

基于 037 第三轮的 32 局自动试玩（4 职业 × 8 个种子）和 408,000 次路线模拟整理。上一版见 `walkthrough-2026-10-13.md`，本版加入了城塞オークスドーン、霧の古戦場、地鳴りの峡谷、两名新同行者和永久强化道具。

## 0. 数据来源和局限
- 试玩脚本离线运行、只用准备好的文本；每步优先试没选过的选项，推进章节的选项放最后；战斗用 heuristic 策略；战败后重来一次。
- 为了让三条第三章路线都有样本，脚本按种子轮换优先走的路线；经过城塞时多数局会招募リーゼ，所以「村路线带リーゼ」的局偏多。这不是无偏的玩家抽样。
- 脚本仍然不会为 Boss 刻意准备，死亡率高于真人。难度数字以第 3 节的路线模拟为准。

## 2. 路线结构
```
王都 ─ 闇の森 ─┬─ 麓の村 ──────────────┐
               ├─ 霧の古戦場 ───(村の裏手)─┤
               └─ 洞窟の水路 ─ オークスドーン ─┬─ 霧の古戦場
                                              └─ 地鳴りの峡谷 ─(避難所の裏手)─┘
                                                                     └→ 竜の谷 → 王都に凱旋
```
- 第三章三条路线各有基调：村＝火・冰，古戦場＝不死（弱光），峡谷＝土（抗物理、弱水）。
- 古戦場和峡谷最终都汇入村子，Xanxus、氷霜の巨狼等主线事件不会错过。

## 4. 各章要点
### 第 1 章 王都
- 开局国王给 100G 和薬草；侍従给聖水 ×2。
- 鍛冶屋的アダマンタイトの鎧（60G）和氷の護符（50G）只能二选一，取决于你更想要减伤还是冰属性。
- 魔法店带上ワーロック：之后 Xanxus 的「死んでも従わない」只有他能救。

### 第 2 章 闇の森
- ゴブリン砦（可选）：**本作最常见的死亡点**（6 局最终死在ゴブリン王）。带ロビン的话，王开战即眩晕 2 回合。打不过就从入口「砦を出て十字路へ戻る」。
- 精霊の泉：「泉の水を汲む」可以拿到给エリオ的礼物。
- 封印の洞窟 → 地底の温泉 →「湯の流れを辿る」→ **オークスドーン**。

### オークスドーン
- 本営：ヴァルター的十年前证词（线索）、推薦状、开通东の峠。
- 礼拝堂：リーゼ（推薦状／聖水／说服），支线「古戦場の鐘」。
- 工房：守護団の鎖帷子（40G）；交聖銀＋30G 打暁光の武器（对亡者最强，对白竜几乎无效）；支线「工房の火床」（焼けた溶岩石 → 防具＋1）。
- 樫の葉亭：峠的传闻（线索）、エリオ。

### 第 3 章
- **村**：慎重接近或冲进火海；救リク；Xanxus 的最后通牒（没带ワーロック时拒绝＝死亡）。
- **古戦場**：骨の野 → 見張り塔（亡灵士兵的证词＝线索，外套，休息一次）→ 屍鬼の沼 → 墓守の礼拝堂（ゼボク按你和他的关系登场）。鐘を鳴らす完成支线。
- **峡谷**：落石の道 → 鉱夫の野営跡（日记＝线索，休息一次）→ 白い爪痕の崖（线索）→ 岩の巨人 → 大ワーム。

### 第 5 章 真结局
- 告发将军需要白い竜鱗，或至少两条线索。本版新增 5 条线索来源：守護団の証言、峠の噂、亡霊兵士の証言、鉱夫の日記、白い爪痕。
- 最终战的助力：国王的近卫兵、ロビン＋砦攻略、ミーナの結界、ローベルトの刻印、霜封じの護符。

## 6. 结论
1. **路线雷同的问题明显缓解**：到访地点重合率从 0.65 降到 0.55，三条第三章路线各有各的敌人、同行者和线索。
2. **真结局可以打出来了**：0/32 → 4/32，新的线索来源让告发条件更容易满足。
3. **各职业有自己擅长的路线**：法师走古戦場、盗賊走峡谷明显更好；勇者和僧侶三条都差不多。

## 7. 仍然存在的问题（待决定）
1. **ゴブリン王**：6 局最终死在这里，其中 4 局重来后又死（法师和盗賊）。砦是可选的高难地下城，这是你确认过的方向；但第一次进砦的玩家没有任何预警。建议在三層の鉄門前加一句能听到王的咆哮的描述，让玩家知道前面有大家伙；数值不动。
2. **法师的村路线**偏难（比古戦場低 9.95pp），原因在村子的旧内容（火の精霊、イグニス战前的消耗）。要不要给村路线加一个法师能用的补给点，等你决定。
3. **从未到达的内容**：夜の路地のゼボク戦、宿屋の深夜の襲撃、Xanxusの分身。它们需要特定的选择顺序，试玩脚本碰不到；不代表有 bug，但说明这些内容的入口比较隐蔽。
