# 剧本 v5：第 5 章「王城への帰還」（设计负责人，2026-10-12）

原则沿用 `scenario-v2.md` 第 0 节。日语正文**逐字使用**。

## 0. 设计意图
- 现在的第 5 章只有"回城 → 汇报"一步。扩展成一个可以探索的章节：凯旋后的城下町、可选潜入的将军宅邸、和国王的私下谈话、ドラコ的先发制人。
- **前面的支线在最终决战里得到回报**：帮过的人会在ドラコ战中以各自的方式提供支援（第 4 节）。不做支线照样能赢，做了的玩家会感到"一路的选择都有意义"。
- 证据的来源再增加一条强证据（白竜の日誌），并且让持有证据成为一种风险（会被刺客盯上）。

## 1. 结构与地图 `royal_return`
```
R1 凱旋の城門 → R2 凱旋の城下町（枢纽）─┬→ 宿屋 / 道具屋 / 魔法店 / 鍛冶屋（现有地点）
                                          ├→ R3 将軍の屋敷（可选，子地图：R3a 夜の庭 → R3b 凍てつく回廊 → R3c 将軍の書斎）
                                          ├→ R4 王の私室（可选）
                                          └→ R5 凱旋の間（现有的 castle_report）
```
- イグニス结束以后（`ignis_last_breath` 和 `ignis_purified` 里的「王城へ戻り、国王に報告する」），改为前往 **R1**，不再直接进入凯旋の間。
- 城下町的四家店、宿屋都沿用现有地点，从 R2 进出（地点里现有的「城に戻る」，在第 5 章期间改为回到 R2）。
- 这一章不能返回森林、村子和竜の谷（剧情上已经凯旋）。

## 2. 节点正文

**R1 `royal_gate`「凱旋の城門」**
- description：城門をくぐると、花びらと歓声があなたを迎えた。邪竜の脅威が去ったことは、すでに城下町じゅうに知れ渡っている。人混みの向こうで、将軍ドラコが穏やかに手を振っていた。
- 动作：「城下町へ進む」→ R2；首次到达时设置 flag `returned_to_capital`

**R2 `festival_town`「凱旋の城下町」**
- description：城下町は祝祭の飾りで埋め尽くされている。祝杯をあげる人々の間を、王国の近衛兵たちが慌ただしく行き来していた。
- 动作：
  - 「宿屋へ向かう」「道具屋へ向かう」「魔法店へ向かう」「鍛冶屋へ向かう」（现有地点）
  - `go_general_mansion`「将軍の屋敷へ向かう」→ R3a｜条件（满足任一）：`heard_gald_rumor`、`noticed_general_frost`、持有白い竜鱗、`heard_xanxus_betrayal`（玩家得先有怀疑将军的理由）｜secret（条件不满足时不显示）
  - `request_king_audience`「国王に内密の謁見を願い出る」→ R4｜条件：揭发条件中的线索或证据至少有 1 项（scenario-v2 3.5 的线索 flag、白い竜鱗、白竜の日誌 中任一）｜secret
  - `go_report_hall`「凱旋の間へ向かう」→ R5（现有的 `castle_report`）
- **城下町的回报事件**（到达 R2 时，按条件依次在系统日志里各出现一次；只有文字，不发东西。具体支援在第 4 节）：
  - `mina_quest_done`：ミーナが駆け寄ってきた。「無事でよかった！ 師匠と一緒に、とっておきの術を用意してあるんです」
  - `riku_returned`：人混みの中から、リクが手を振っている。避難していた村の人たちも、王都まで凱旋を見に来たらしい。
  - `saved_gald`：「よう、英雄！」ガルドが荷車の上から叫んだ。「とっておきの品を仕入れてきたぜ。道具屋の隣で店を広げてる」
  - `robert_hammer_returned`：鍛冶屋の前で、ローベルトが無言で手招きしている。

**R3a `mansion_garden`「将軍の屋敷・夜の庭」**（子地图 `general_mansion` 的入口）
- description：夜更けの将軍の屋敷は、祝祭の喧騒が嘘のように静まり返っている。庭の噴水だけが、なぜか凍りついていた。
- 动作：
  - `sneak_into_mansion`「裏口から忍び込む」｜1d20+dex，DC13｜成功 → R3b；失败 → R3b，并且 R3b 的战斗中敌人先手。成功文：物音ひとつ立てず、裏口の錠を外した。失败文：扉が軋み、屋敷の奥で何かが動く気配がした。
  - `robin_picks_lock`「ロビンに錠を開けてもらう」｜条件：`recruited_robin`｜判定不要 → R3b。结果文：ロビンが細い針金を差し込むと、錠はあっさりと外れた。「将軍様の屋敷ってのは、案外ちょろいもんだね」
  - `leave_mansion`「城下町へ戻る」→ R2
- 观察对象 `frozen_fountain`（凍った噴水）：判定不要，once → flag `noticed_general_frost`（若还没有）。文：真夏の夜だというのに、噴水の水は芯まで凍りついている。

**R3b `mansion_corridor`「将軍の屋敷・凍てつく回廊」**
- description：廊下の壁も床も、薄い氷に覆われている。突き当たりの扉の前に、氷でできた鎧の番兵が二体、無言で立っていた。
- 敌人：氷の番兵 ×2（新）
- 动作：战斗；「番兵の巡回の隙を突く」（1d20+wis，DC15，成功 → R3c，失败 → 开战，敌人先手）
- 胜利 → R3c；败北：HP 1，回到 R2（屋敷的可选内容不导致 game over）。败北文：氷の拳に打ち据えられ、気がつくと城下町の路地裏に倒れていた。

**R3c `mansion_study`「将軍の屋敷・書斎」**
- description：書斎には古い書物が積み上げられ、机の上に一冊の日誌が開かれたまま置かれていた。部屋の奥には、白い鱗で飾られた小箱がある。
- 动作：
  - `take_draco_journal`「日誌を手に取る」｜once｜获得 `draco_journal`（白竜の日誌）。结果文：日誌には、十年前に紅竜の傷へ霜を打ち込んだこと、Xanxusと交わした密約、そして王国を手に入れる計画が、几帳面な文字で記されていた。
  - `open_scale_box`「小箱を開ける」｜once｜获得 `frost_seal_charm`（霜封じの護符，新物品）。结果文：小箱の中には、白い鱗を編み込んだ護符が収められていた。添えられた札には「我が冷気を鎮めるもの」とある。
  - `leave_mansion_study`「屋敷を出る」→ R2

**R4 `king_private_room`「王の私室」**
- description：豪奢な寝室の窓辺で、国王エドワードが一人、月を見上げていた。あなたに気づくと、王は静かに人払いをした。
- 动作：
  - `confide_in_king`「将軍への疑いを打ち明ける」｜once｜flag `king_trust`
    - 结果文：王は長い沈黙の後、重い口を開いた。「……十年前、竜の谷へ兵を送れと進言したのは、ドラコだった。わしはそれを信じ、紅竜を怒らせてしまった。もしそなたの言う通りなら……その時は、わしが近衛兵に命じよう。そなたを守れ、と」
  - `ask_king_rest`「城に泊めていただけないか頼む」｜条件：`king_trust`｜判定不要｜HP/MP/SP 全回复，**不会遭到刺客袭击**（第 3 节）。结果文：王の計らいで、城の客室に通された。衛兵が扉の前に立ち、あなたは久しぶりに安心して眠った。
  - `leave_king_room`「城下町へ戻る」→ R2

**R5**：现有的 `castle_report`（凱旋の間），文字和条件不变；揭发条件的强证据增加 `draco_journal`（见第 5 节）。

## 3. ドラコ的先发制人：宿屋的刺客
- **触发**：在第 5 章期间使用宿屋的付费休息（`rest_at_inn`），并且满足下列全部条件时，休息前先发生事件：持有白い竜鱗或白竜の日誌；还没有 `draco_revealed`；还没有发生过这个事件（flag `assassins_attacked`）。
- **新地点 `inn_night_ambush`「宿屋・深夜の襲撃」**
  - description：真夜中、部屋の窓が音もなく凍りつき、砕け散った。白い装束の刺客が二人、氷の刃を手に滑り込んでくる。
  - 敌人：氷の刺客 ×2（新），`flee_allowed: false`
  - **ロビンの警告**：持有 `recruited_robin` 时，战斗开始前追加一段文字，并且让敌人先手的效果失效、玩家先手：「起きな！ 窓の外に誰かいる！」ロビンの声で飛び起きると、すでに刺客が窓に手をかけていた。
  - 胜利：获得 `assassin_crest`（刺客の徽章，新物品，作为线索）、flag `assassins_defeated`，然后正常完成休息（全回复）。结果文：倒れた刺客の懐から、白い竜を象った徽章がこぼれ落ちた。将軍家の紋章だ。
  - 败北：不 game over。HP 1，**白い竜鱗被夺走**（如果持有；日志不会被夺走，因为它被藏在别处），flag `scale_stolen`。败北文：気がつくと朝だった。部屋は荒らされ、白い鱗だけが消えていた。
    - 失去鳞片的玩家，仍然可以靠日志或其他线索揭发（这就是多来源的意义）。
- `assassin_crest` 加入揭发的线索列表（作为一项线索 flag `has_assassin_crest`，持有时视为成立）。

## 4. 最终决战的支援（ドラコ战）
完成对应支线的玩家，在ドラコ战中获得下列支援。每项都在战斗开始时（或进入二阶段时）写一段文字。数值由工程设定，目标见第 6 节。
| 条件 | 支援 | 时机 | 文字 |
|---|---|---|---|
| `king_trust` | 近衛兵の包囲：一阶段ドラコ不能使用「護衛の構え」，防御 -4，近衛兵每回合 13 点物理伤害（025 修订） | 一阶段开始 | 「近衛兵、将軍を囲め！」国王の号令が王の間に響いた。 |
| `recruited_robin` 并且 `cleared_goblin_fort` | ロビンの盗み：二阶段ドラコ的最大 HP ×0.85（026 修订：一阶段的削弱对胜负没有影响） | 一阶段开始（台词）＋ 二阶段开始（效果） | 一阶段：「昨夜のうちに、あんたの部屋から妙な首飾りをくすねといたよ。白い竜の力の源なんだろ？」柱の陰からロビンの声がした。／二阶段：白竜の巨体から、一瞬だけ光が抜け落ちた。ロビンが盗んだ首飾りの効果らしい。 |
| `mina_quest_done` | ミーナの炎の結界：二阶段玩家受到的冰伤 ×0.8 | 二阶段开始 | 「今です、師匠！」ミーナと青いローブの魔法使いが、あなたの周りに炎の結界を張った。 |
| `robert_hammer_returned` | 霜断ちの刻印：二阶段玩家的普通攻击追加火属性追击 1d6 | 二阶段开始 | 剣の刻印が赤く輝いた。ローベルトが打ち込んだ霜断ちの刻印だ。 |
| `saved_gald` | 城下町的ガルド之店出售「火竜の油」（火属性消耗品，2 个，40G） | 第 5 章期间 | （商店的 greeting 改为「とっておきだ。白い竜には火が一番効くって話だぜ」） |
| `riku_returned` | 竜の秘薬 已经在第 3 章给过，这里不追加支援 | — | — |

- 战斗日志里每项支援都要显示出来，让玩家明白"这是因为我当初帮了谁"。

## 5. 证据规则的更新
- 强证据（持有任一即可揭发）：白い竜鱗、**白竜の日誌**（新）
- 线索（至少 2 个）：原有的线索 flag + `heard_xanxus_betrayal` + `has_assassin_crest`（新）
- 凱旋の間的 `report_with_evidence` 文字不变。持有日志时，揭发文追加一句：あなたが日誌を掲げると、ドラコの表情から初めて笑みが消えた。

- 支援按"有/无"做对照实验，报告每项的贡献。
