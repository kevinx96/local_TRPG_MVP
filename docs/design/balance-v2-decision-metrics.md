# 数值 v2：从"通关率"到"决策敏感度"（r5，主要决定已确认）

设计负责人，2026-10-20。依据：人类试玩存档 `e2b9fdd9…`（exe 打包版，`dragon_rpg_hybrid.json`）、`host/combat.py`、`eval/reports/037-*`、`eval/balance/checkpoints.json`。本文只提方案，不改数据。

## 决定记录（2026-10-20，和用户确认）

1. **莽夫的通关率接近 0%**：完全不解谜、只做少量交互的玩家，通关率目标 ≤ 5%。
2. **氷の護符只能对冰弱点的敌人使用**（敌人当前的冰抗性 > 1），其他时候不能使用。是否保留"可重复使用"由本文第 4 节 B1 讨论。
3. **整体威胁偏低**：现在的体感是"血量忽上忽下，但总体很安全"。威胁要整体上调，同时压低波动（第 1.6 节、第 4 节 G）。
4. **火コウモリ竜的回复和它造成的伤害挂钩**：对普通敌人维持现状；对火抗敌人，既难以造成伤害，也回不了血。
5. **国王开场说出弱点：保留。**

追加（r3，同日）：

6. **氷鉄の大剣的获取方式暂时保留**（勇者到铁匠铺就能拿到）。用户另有尚未写进剧本的伏笔，会作为 Ignis 的另一层准备。
7. **魔法使い的莽夫上限放宽到 ≤ 15%**，其余职业仍为 ≤ 5%。
8. **敌人命中率统一为 100%**；角色按 AGI 获得少量闪避，上限 20%。
9. **精英敌人要有按百分比造成伤害的招式。**
10. **重新设计等级机制，并增加新技能。** 分工：技能内容和追加剧情由用户设计；数值和技能效果的允许范围由本文规定（第 5 节）。

追加（r4，同日）：

11. 通关率目标确认：P0 ≤ 5%（魔法使い ≤ 15%），P1 15–35%，P2 55–75%，P3 ≥ 80%。
12. 等级节奏确认：满级 8；Lv3 / 5 / 7 二选一；偶数级自动强化或获得被动。
13. **升级时回满 HP / MP / SP：保留**，更符合游戏直觉。
14. 勇者的神聖の庇護：**加 1 回合冷却**，不需要另立"每场一次"的规则（G3）。

追加（r5，同日）：

15. **EXP 改为战斗驱动**：杂兵和可重复的战斗都给 EXP；跳过的战斗不给。取消主线里程碑直接升级。
16. **主动技能固定获得，被动技能二选一。** 技能形式不拘泥于"・改 / 替换"，由用户设计。
17. **选择交给玩家**：规则和 UI 不替玩家判断哪个选项更好。

## 0. 结论

这次能"莽过去"，是四个因素叠在一起：

1. **主因：持续回复 ≥ Boss 输出。** 火コウモリ竜每回合固定回 3 HP（虹晶樹之后回 6），而 Ignis 每回合期望伤害只有约 5。强化后玩家每回合**净回血**，这场战斗在数学上几乎输不了。
2. **主因：氷の護符是无消耗、100% 命中、可无限使用的弱点攻击**，开局 100G 就能在第一家店买到。
3. **次因：怪物的威胁整体偏低，而且波动大。** 均值低，所以玩家总体安全；方差大，所以血量忽上忽下（第 1.6 节）。另外 Ignis 的 `physical: 0.65` 和"物理攻击完全无效"的设定矛盾。
4. **测量盲区：** 037 报告里，勇者带强化火コウモリ竜打 Ignis 的胜率是 97.2%，不带同伴也有 88.2%，Boss 的目标是 60–75%。但验收没有胜率上限，火コウモリ竜反而被当成新同伴要超过的基准。

勇者数值不是主因：Ignis 是被按 INT 5 计算的护符打死的。不过等级完全挂在主线 flag 上，到 Ignis 时必定是 Lv5，成长没有任何决策含量。

### 1.2 资源：完全没有压力
通关时背包里还剩：薬草 ×7、治療の巻物 ×9（合计 270 HP，相当于最大 HP 的 6.75 倍）、生命の果実 ×3、四种霊薬各 1 个，金币 706G 一分没花。**整局一个回复道具都没用过。** 这些回复几乎全是战斗自动掉落的，所以莽夫照样拿得到。精霊の泉的休息可以无限次回满（本局休息了 3 次）。

### 1.3 判定：失败没有代价
一共 14 次判定，10 次成功。失败的后果只是多打一场战斗，而战斗不花资源，所以失败也不花资源。**战斗成本一旦为零，所有"绕开战斗"的选择就都失去了价值。**

### 1.4 Ignis 战拆解（按引擎公式估算期望值）

前提：勇者 Lv5、STR 20、INT 5、革の鎧（防御 1）、紅玉の護符（火伤 ×0.7）。

| 玩家手段 | 每回合期望伤害 | 击杀所需回合 |
|---|---|---|
| 鉄の剣普攻 | ≈4.2 | ≈40 |
| 氷の護符（无限） | ≈9.0 | ≈19（实测 20） |
| 氷鉄の大剣 | ≈16.7 | ≈10 |

| 玩家生存 | 每回合净 HP |
|---|---|
| 强化火コウモリ竜（+6） | **+1.2**（不可能输） |
| 火コウモリ竜（+3） | −1.8 |
| 无同伴 | −4.8 |

注意：**氷鉄の大剣是主线上接受イアン的委托就直接给的**，玩家只要装备上就能打出准备路线的伤害。它现在不算一个决策（见 B8）。

### 1.5 虹晶樹
130 HP，物理 0.6，每 2 回合轮换抗性。护符和火コウモリ竜在每个阶段总有一个能打出伤害，属性轮换只是把战斗拉长，没有逼玩家做选择。

### 1.6 全局威胁扫描（印证"整体都很简单"）

按引擎公式计算每回合期望受到的伤害；玩家采用 checkpoint 的等级和最大 HP，防御 1、回避 0，不计同伴，不计敌人存活时间。CV 是每回合伤害的变异系数（标准差 ÷ 均值），越大越"忽上忽下"。

| 遭遇 | 类别 | 每回合期望 / 最大 HP | 预算上限 | CV |
|---|---|---|---|---|
| 闇の森・スライム等 | trash | 4–11% | 15% | 0.5–0.9 |
| ファイアスライム（Lv4） | trash | **4%** | 15% | 1.18 |
| 大ゴブリン×2 场 | elite | **8%** | 25% | 1.09 |
| 森狼 / 猛犬 | elite | 17% | 25% | 0.9–1.1 |
| 氷の精霊 | elite | 16% | 25% | 0.90 |
| スライム王 | boss | 23% | 35% | 0.59 |
| ゼボク | boss | 18% | 35% | 0.83 |
| **氷霜の巨狼** | boss | **10%** | 35% | **1.12** |
| **邪竜イグニス** | boss | **14%** | 35% | **1.21** |
| 剣聖ドラコ | boss | 18% | 35% | 0.45 |
| 洞窟三场 elite（Lv2） | elite | 30–41% | 25% | 0.3–0.5 |
| ゴブリン王+弓 | boss | 41% | 35% | 0.94 |

结论：

- **主线上的 Boss 大多只有预算的 1/3 到 1/2。** 例外是可选内容（洞窟、砦），而这次试玩者在洞窟里本来就是一路掉血的。
- **CV ≈ 1 的敌人很多**：1d21@55%、1d24@50%、1d40@20% 这类"命中低、骰子大"的写法，均值低、方差大，正好就是"忽上忽下但不危险"的体感。
- 原来的伤害预算**只设了上限，没有下限**，所以偏低的遭遇从来没有被拦下来。

## 3. 新的衡量方法

原则：**问的不是"能不能赢"，而是"做对决策和不做决策的差距有多大"**。

### 3.1 玩家原型策略（路线级，只跑确定性引擎）

| 原型 | 行为 | 通关率目标（草案） |
|---|---|---|
| **P0a 零交互** | 只执行推进主线所必需的行动；不和 NPC 搭话，不购物，不带同伴，不使用线索；被迫的战斗照打；战斗掉落自动拾取；战斗中反复使用期望伤害最高的零成本行动；HP < 30% 时用回复 | **≤ 5%**（魔法使い ≤ 15%） |
| **P0b 少量交互** | P0a，外加最多 3 次可选交互（买一件被明确提示的商品、借一个免费同伴、听国王的提示）；拿到的装备会装上（包括氷鉄の大剣）。**就是本次试玩者** | **≤ 5%**（魔法使い ≤ 15%） |
| P1 普通 | P0b，加上主线路过的支线，但不追线索链 | 15–35% |
| P2 准备 | P1，加上设计中的关键准备链（见 B8） | 55–75% |
| P3 全收集 | 全部支线和商店 | ≥ 80% |
| P2s 绕路型（变体） | P2，但能绕开的战斗全部绕开 | 与 P2 相差 ≤ 10pp；等级相差 ≤ 1 |
| P0g 莽夫 + 刷级（变体） | P0b，加上把可重复战斗刷到资源允许的极限 | 只报告，不设门槛（第 5.2 节） |

P2 和 P3 的数字只是草案，需要等阶段 A 出了基线再定。现有的 `attack_only` 和 `heuristic` 都没有模拟到"无限护符 + 免费同伴"这套配置，P0b 就是用来补这个洞的。

### 3.2 指标（全部设为门槛）

| 编号 | 指标 | 定义 | 目标（草案） |
|---|---|---|---|
| M1 | 莽夫上限 | P0a、P0b 的主线通关率 | ≤ 5%；魔法使い ≤ 15% |
| M1' | 决策梯度 | P0 < P1 < P2 < P3 严格递增，相邻两级之间的差距 | 相邻差 ≥ 15pp |
| M2 | 准备边际价值 | 在目标遭遇上：胜率(全准备) − 胜率(全准备去掉 k) | 每个关键准备 ≥ +10pp；任何非关键单件 ≤ +25pp |
| M3 | 回复覆盖率 S | 每回合期望回复 ÷ 每回合期望受到的伤害 | P0b 配置下 Boss 战 S < 0.5 |
| M3' | 赛跑比 | 玩家杀敌回合 ÷ 玩家资源耗尽回合（HP 加可用回复） | Boss：P0b > 1.3（必输），P2 为 0.6–0.9 |
| M4 | 回合上限 | 任何策略下 Boss 回合中位数 | ≤ 14；> 18 判为沙袋战 |
| M5 | 资源压力 | P1 到达最终 Boss 时：库存回复 ÷ 最大 HP；路线上回复道具使用率；未花金币占比 | 库存 ≤ 1.5 倍最大 HP；使用率 40–80%；未花金币 ≤ 30% |
| M6 | 支配动作占比 | Boss 战中玩家用得最多的那个行动所占回合比例 | 零成本行动 > 70% 且同时是 P0 的选择 → 标红 |
| M7 | 判定代价 | crucial 判定成功/失败两个分支的通关率差或资源差 | 失败分支通关率 −5pp 以上，或期望资源 −15% 以上 |
| M8 | 同伴边际上限 | 每个同伴 × 每个 Boss 的胜率提升 | 10–20pp，上限也要拦；不再拿任何同伴当基准 |
| **M9** | **威胁带宽** | 每回合期望受到的伤害 ÷ 最大 HP | 由"只设上限"改为区间：trash 10–15%，elite 18–25%，boss 28–35% |
| **M10** | **波动** | 每回合受伤的 CV | 命中改为 100% 后，普通攻击 ≤ 0.5；超过的大招必须有预告（蓄力回合） |
| **M11** | **战斗成本** | 一场战斗期望损失的 HP ÷ 最大 HP（不计回复，计入敌人存活时间） | trash 10–25%，elite 30–50%，boss 70–110%（必须用回复或防御） |
| **M12** | **技能使用** | P2 的 Boss 战中：技能回合占比；单个主动技能占全部技能使用的比例；"死选项"（在整个遭遇矩阵里从来不是更优选择的被动选项） | 技能回合 ≥ 35%；单个主动 ≤ 60%；死选项 = 0；同组两个被动的整体价值差 ≤ 10% |
| **M13** | **等级边际** | 同一配置下 +1 级对 Boss 胜率的提升；到达 Ignis 时 P0 和 P2 的等级差 | 每级 +8–15pp；等级差 ≥ 2 |

M9 只看每回合，M11 才是一场战斗真正的成本：例如煤の亡霊每回合伤害很高，但第一回合就死，战斗成本其实很低。M12 和 M13 用来验收第 5 节的新等级和技能。

### 3.3 人类试玩遥测
由脚本自动从存档和 trace 生成每局报告：每场战斗的回合数、结束 HP、玩家行动分布；回复道具获得 / 使用；金币获得 / 花费；判定成功率和失败代价；装备变更次数；关键准备的拿到率和使用率；到达 Boss 时的 HP 和库存回复。把人类试玩放到 P0–P3 旁边比较，判断这个玩家最接近哪种原型。

## 4. 改良方案（分阶段，待审）

### A. 测量先行（工程 spec 046）
1. route 模拟加入 P0a / P0b / P1 / P2 / P3，实现 M1–M13；`targets.json` 升级为 v2。被动二选一（第 5 节）做成策略参数：每个原型按固定规则选，另外穷举全部组合，用来查死选项。EXP 改为战斗驱动以后，路线模拟要记录每个原型到达各节点时的等级。
2. 新增"莽夫配置"checkpoint，复现本次试玩。
3. 存档遥测提取脚本。
4. **验收：先对当前数据跑基线，必须复现本次试玩**（P0b 勇者通关率 > 90%，Ignis 约 19 回合，强化同伴下 S > 1）。复现不了先修测量。

### B. 机制与数值修正（spec 047 起，基线出来后再定具体数字）

**B1 氷の護符：只对冰弱点敌人可用（已定）**
- 规则：目标当前的冰抗性 > 1 时才能使用；虹晶樹按当前阶段判断（只有"紅"阶段可用），这样读懂属性轮换会得到回报。不满足条件时，在 UI 里显示为灰色并说明原因。
- 现在能用的对象：熱岩トカゲ、炎のウィスプ、紅晶ゴーレム、溶岩ドレイク、ファイアスライム、火の精霊、虹晶樹（紅）、**イグニス**、ザンザスの分身、飛竜ノクス。
- **注意：Ignis 本来就是冰弱点，所以这条规则单独解决不了本次的案例。** 让护符连打的玩家打不赢 Ignis，靠的是 B2、B3、B4 一起改，让"护符连打"在赛跑中输掉。护符只负责"能打出伤害"，"能打赢"要靠准备链。
- 次级选项（待定）：保留无限使用；或者另外加上次数限制（例如每场 3 次）。建议先保留无限，等基线出来，用 M2 看还需不需要加限制。

**B2 Ignis：按"赛跑"重新设计**
- `physical` 0.65 → 0.25，和设定一致。
- 设计目标（数字靠模拟定）：P2 大约 8 回合击杀 Ignis；P0b 用护符连打需要 ≥ 15 回合，而它的资源在大约 10 回合内耗尽。粗算：HP 约 140，每回合期望伤害约为勇者 HP 的 30%。
- 命中按 G1 改为 100%，骰子缩小到期望伤害落在区间内，CV ≤ 0.5。真正高伤害的炎の息改成有预告的百分比招式（G2）：先"息を吸い込む"蓄力一回合，下回合放出。玩家在蓄力回合防御，或者有紅玉の護符，就能扛住。
- HP ≤ 40% 进入第二阶段，压力进一步上升，也和现有圣水净化的触发阈值（≤ 40%）对齐。

**B3 火コウモリ竜：回复和造成的伤害挂钩（已定）**
- 规则：回复量 = 本回合火焰实际造成的伤害 × 0.75（强化后 × 1.5）；如果目标的火抗性 < 1，就不回复。
- 对普通敌人：2d3 期望约 4，回复约 3，强化后约 6，和现在一样。
- 对火抗敌人（熱岩トカゲ、ウィスプ、紅晶ゴーレム、ファイアスライム、火の精霊、煤の亡霊、溶岩ドレイク、ザンザス、虹晶樹的紅阶段、**イグニス**）：伤害很低或为 0，而且完全不回复。借来的是火龙，到了火焰地带就使不上力，剧情上也说得通。
- 可选：攻击目标改为"优先打火弱点的敌人"（参照エリオ的 `weak_to:`），这样在多敌人战斗中会多一点操作空间。

**B4 经济与回复**
- 大幅减少战斗自动掉落的治療の巻物和薬草，让回复变成"需要去买、需要做支线才能拿到"的东西。魔法店的巻物 10G → 35G，或者限制库存。
- 精霊の泉：只能回满一次，或者每次休息都会触发遭遇。
- 用 M5 验收。

**B5 虹晶樹**：HP 130 → 约 100；属性不对时伤害降到 0；配合 B1 和 B3，护符和火コウモリ竜各自只在某些阶段有用。用 M4 验收。

**B6 判定**：先不动。B3 和 B4 之后战斗有了成本，判定失败自然就有代价。用 M7 复测。

**B7 勇者成长**：先不动。B1–B4 之后用 M2 看等级的边际价值；如果还是不够，再把一部分永久成长（生命の果実、霊薬）改成只能从支线获得。

**B8 Ignis 的准备链（获取方式保留，等用户的伏笔）**
- 氷鉄の大剣的获取方式不变。因此 P0b 也会装上大剣，**数值上必须保证"大剣 + 免费可得的东西"仍然打不赢 Ignis**（P0b ≤ 5%）。
- 打赢 Ignis 需要的第二层准备，由用户尚未写进剧本的伏笔提供。数值这边只规定它的"分量"：拿到这一层后，Ignis 胜率要从 ≤ 5% 提到 P2 区间（55–75%），按 M2 衡量。
- 在伏笔落地之前，可以先用现有内容当占位：紅玉の護符配合防御时机、アダマンタイトの鎧、圣水净化路线。阶段 A 的基线里单独跑一项"P0b + 大剣"探针，用来确认第一层准备的分量。

**G 全局威胁重做（已定方向）**

先改主线必经的遭遇（森狼、巨狼、Ignis、ドラコ、村子里的 elite），可选内容（洞窟、砦）维持现在偏高的难度。敌人的种类和剧情含义都不变，只调数值。

*G1 命中与闪避*
- 敌人所有攻击的基础命中统一为 100%。命中判定改成：命中率 = 100 − 玩家闪避 − 各种命中惩罚（烟幕、致盲之类的状态仍然有效）。
- 玩家闪避由 AGI 推导，**基础上限 20%**。建议公式：`闪避% = clamp((AGI − 4) × 1.5, 0, 20)`，取整。
- 各职业的目标带宽（具体 AGI 初值和成长由用户在角色模板里定）：

  | 职业 | Lv1 闪避 | 满级闪避 |
  |---|---|---|
  | 勇者 | 2–5% | 6–9% |
  | 僧侶 | 2–5% | 5–8% |
  | 魔法使い | 4–6% | 8–11% |
  | 盗賊 | 12–15% | 20%（上限） |

- 现状：只有勇者和盗賊的模板里有 `agi`，僧侶和魔法使い要补上；角色身上现有的固定 `evade` 字段（勇者 0、魔法使い 2、盗賊 8）改为由 AGI 推导；里程碑成长要包含 AGI。
- 技能和道具提供的临时闪避加成另算，但总闪避不超过 40%，持续不超过 2 回合（见第 5 节）。
- 敌人的伤害骰子要同步缩小：单次期望伤害 ≈ M9 目标 × 最大 HP ÷（1 − 该职业平均闪避）。命中拿掉随机性以后，CV 主要来自骰子，可以压到 0.5 以下。

*G2 百分比伤害招式*
- **每个精英敌人恰好有 1 个百分比招式**：伤害为玩家**最大 HP** 的 15–25%。触发方式二选一：每 3 回合一次（`every_n_rounds: 3`），或者 AI 权重约占 1/3。
- 结算规则：**无视平坦防御（鎧）**；受防御姿态的减伤影响（例如 ×0.5）；**可以被闪避**；对应元素的抗性道具有效（例如紅玉の護符对火属性的百分比招式有效）。这样能防住它的是"时机和准备"，而不是堆装备。
- 多个精英同场时，同一回合百分比伤害合计不超过 30%。
- Boss 可以有 1 个**带预告**的百分比大招：最大 HP 的 30–45%，先蓄力一回合。P2 的应对手段要能把它压到 ≤ 20%。
- 杂兵不设百分比招式。
- 设计意图：百分比伤害不会被等级带来的 HP 成长稀释，后期精英依然有威胁；防御时机、闪避、抗性准备就成了真正的决策。
- 引擎现在没有"按最大 HP 比例伤害"的敌人招式（只有按最大 HP 比例的回复），需要工程新增。

*G3 修掉"免费致死保护"*
- 勇者的神聖の庇護消耗为 0，又带"致死伤害保留 1 HP"。玩家每回合防御就永远不会死，同伴再慢慢磨死敌人，这是一个无限拖延的漏洞。
- 改为（已定）：神聖の庇護加 **1 回合冷却**，用完后下一回合不能再用，所以没法每回合都防御。
- 通用规则：所有带"致死保留 1 HP"的技能，都必须有冷却（≥ 1 回合）或资源消耗，二者至少有一个。现有的不屈の構え（2 SP）、影隠れ・改（2 SP）、聖なる守護（6 MP）已经满足。

### C. 验收
1. 用 v2 门槛全量重跑：M1、M3、M4、M9 是硬门槛，其余先报告。
2. 人类试玩两局，一局莽、一局探索，用遥测对比。预期莽的那一局会在 Ignis 前后失败。

### 执行顺序
A（测量）→ G1 / G3 / B3 / B1（机制改动，不依赖新内容）→ 第 5 节的等级框架和用户设计的新技能 → G2、B2、B4、B5（数值，要在新技能就位后才能定）→ C。B8 的第二层准备随用户的伏笔一起进入。

## 5. 等级与技能框架（数值和效果范围）

分工：**技能的名字、主题、叙事和追加剧情由用户设计；本节规定数值区间和允许的效果类型。** 用户设计的技能只要落在区间内，就可以直接交给工程录入，再由模拟按 M12 / M13 验收；超出区间的，需要单独说明理由。

### 5.1 现状的问题
- 等级由 4 个主线里程碑触发，到 Ignis 必定是 Lv5，**等级和决策无关**。
- 每个职业只有 2 个初始技能，加上 Lv3 和 Lv5 各 1 个（多数是"・改"替换），**战斗中实际可选的行动只有 3–4 个**。
- 升级时回满 HP / MP / SP（保留，属于游戏直觉）。

### 5.2 等级机制（r5）
- **满级 8**（Ignis 之前最多到 7，Lv8 留给 Ignis 之后的内容）。
- **EXP 来源**，全部由引擎按数据结算，不经过模型：
  - **每场战斗胜利都给 EXP，包括杂兵和可以重复的战斗**；
  - 支线完成、线索链（伏笔）揭开也给 EXP；
  - **用隐密、交涉、绕路等方式跳过的战斗不给 EXP。**
  - 取消"主线里程碑直接升级"，等级完全由 EXP 决定。
- 这样"打还是绕"就成了玩家自己的取舍：绕开能省资源，但拿不到 EXP。数值上要保证两边都走得通：
  - **EXP 比例（建议）**：杂兵 : 精英 : Boss ≈ 1 : 3 : 8；支线和伏笔的 EXP 要足够补上被绕开的战斗。
  - **"绕路型"玩家**（P2 的变体：能绕的战斗全部绕开，但支线和线索都做）到达 Ignis 时，等级和 P2 相差不超过 1 级。
- **到达 Ignis 时的等级目标**：

  | 原型 | 到达 Ignis 时的等级 |
  |---|---|
  | P0 | 4 |
  | P1 | 5 |
  | P2 | 6 |
  | P3 | 7 |

  敌人数值按 P2 的等级调。M13 要求每级 +8–15pp，P0 和 P2 的等级差 ≥ 2。
- **每级成长**：最大 HP +15–20% 基础值；主属性 +2，副属性 +1；MP / SP 上限 +10–15%；AGI 按 G1 的带宽成长。
- **升级时回满（保留）。** 升级发生在战斗胜利之后，所以它本身就是"打了仗"的回报。资源压力（M5）按"包含升级回满"计算。
- **刷级是玩家的选择，不禁止。** 数值这边只做测量，不设硬门槛：
  - 新增原型 **P0g（莽夫 + 刷级）**：P0b 加上把所有可重复战斗刷到资源允许的极限。报告它到达 Ignis 时的等级和通关率。
  - **唯一要防的是"零成本刷级"**：如果存在"免费回满 + 可重复战斗"的循环（例如精霊の泉可以无限休息，休息又会触发遭遇），刷级就没有任何代价。所以 B4 对精霊の泉的限制必须和 EXP 改动同时上线。
  - 刷级本身的代价来自资源：每场战斗都在消耗 HP 和回复道具。报告"每 1 级刷级的期望资源消耗"，供设计参考。
- 旧存档：沿用"不追溯成长"的规则，由工程负责迁移。

### 5.3 技能获取节奏（r5）

| 内容 | 获取方式 |
|---|---|
| 主动技能 | **固定获得**（每个职业由用户指定在哪些等级获得哪个技能）；不需要拘泥于"・改"或替换旧技能，具体形式由用户设计 |
| 被动技能 | **在指定等级二选一**，选择不可撤销 |

- 这样主动技能固定，**美术只需要为固定的主动技能做战斗动画**；被动没有动画，策略选择也相对简单。
- 建议的节奏（可调）：Lv1 有 2 个初始主动；Lv3 / 5 / 7 各获得 1 个固定主动；Lv2 / 4 / 6 / 8 各一次被动二选一。满级时每个职业 5 个主动、4 个被动（需要设计 8 个被动选项）。
- **选择由玩家做，规则不替玩家做决定**：游戏里不推荐、不提示"哪个更好"。数值上只保证两点：
  1. 两个被动选项的整体价值相差在 ±10% 以内；
  2. **每个被动选项，在遭遇矩阵里至少有一类情况是更优的选择**（没有"死选项"，M12）。

  至于哪个选项适合哪种打法，由玩家自己摸索。

### 5.4 数值区间

以 **B = 同等级下该职业普攻的期望伤害** 作为基准单位（已计入命中，不计敌人抗性）。资源指 SP 或 MP 的上限。

**攻击类**

| 类型 | 伤害 | 消耗 | 说明 |
|---|---|---|---|
| 普攻 | 1.0 B | 0 | — |
| 标准技能 | 1.4–1.8 B | 资源上限的 15–25% | 一场战斗能用 4–6 次 |
| 大招 | 2.5–3.5 B | 资源上限的 40–60%，或冷却 ≥ 3 回合 | 一场战斗 1–2 次 |
| 群体攻击 | 每个目标 0.7–1.0 B | 同标准技能 | — |
| 属性攻击 | 对弱点 ×1.5–2.0，对抗性 ×0.25–0.5 | — | 免疫（×0）只用于 Boss 的主题属性 |
| 持续伤害 | 每回合 ≤ 敌人最大 HP 的 5%，持续 ≤ 3 回合，不叠加 | — | — |

**回复与防御**

| 类型 | 范围 | 说明 |
|---|---|---|
| 单次回复 | 最大 HP 的 20–35% | — |
| 大回复 | 最大 HP 的 50–60% | 消耗 ≥ 资源上限的 60% |
| 技能回复的单场总量 | 僧侶 ≤ 最大 HP 的 80%；其他职业 ≤ 30% | 这是 M3 回复覆盖率的主要来源 |
| 防御姿态 | 受伤 ×0.5（标准）/ ×0.25（强化，需要消耗） | 零消耗的防御只允许 ×0.5 |
| 致死保留 1 HP | 必须带冷却（≥ 1 回合）或资源消耗（G3） | 不能每回合都用 |

**控制与增益**

| 类型 | 范围 | 说明 |
|---|---|---|
| 临时闪避 | +10–15%，持续 ≤ 2 回合 | 总闪避 ≤ 40% |
| 减益：敌人伤害 | −20–30%，持续 2–3 回合 | 可以用来应对百分比招式的预告 |
| 眩晕 / 跳过回合 | 1 回合 | 对 Boss 每场最多一次，或者 Boss 免疫 |
| 打断蓄力 | 允许，但要有消耗或冷却 | 用来对付 Boss 的预告大招 |
| 被动（每个） | 整体等效 ≤ +15% 输出或生存；4 个被动叠加 ≤ +40% | 不允许"每回合固定回复"类的被动（避免重复火コウモリ竜的问题）；条件触发型（例如"HP 低于 50% 时闪避 +10%"）允许 |

**资源**：SP 每回合回复 1 维持不变；MP 战斗中不自动回复。Boss 战中技能回合占比的目标是 35% 以上（M12）。

### 5.5 和其他改动的关系
- 敌人命中 100% 以后，**防御姿态、闪避增益和伤害减益的价值都会上升**，这些是新技能设计的重点方向。
- 精英的百分比招式和 Boss 的预告大招，**每个职业在 Lv5 之前至少要有一种应对手段**（防御强化、闪避、减益或打断，任选其一）。这个手段可以来自固定主动技能，也可以来自被动；但如果来自被动，**两个被动选项都要满足**，免得玩家因为某一次选择而失去应对手段。
- 每个职业至少要有一个对"火抗 / 冰弱点"敌人有效的手段（属性攻击、或者通过道具），这样 B1 的护符限制不会让某个职业在火焰地带无计可施。
