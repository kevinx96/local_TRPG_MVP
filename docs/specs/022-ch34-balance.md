# 022 第 3、4 章数值调整

021 的结果：在会休息的策略（hp70）下，主线通关率是 勇者 49.8% / 僧侶 29.8% / 魔法使い 19.4% / 盗賊 5.6%。失败集中在 **D1 `valley_entrance`（煤の亡霊 ×2）**：每 500 次中失败 180–334 次。其次是イグニス战（41–97 次）和史莱姆王（在泉边休息引来的，37–48 次）。

## 设计决定
1. **D1 是谷口的"开场战"，不能成为墙**。可调整的范围：煤の亡霊的数量（允许降到 1 只）、HP、伤害、物理抗性（0.5 可以放宽到 0.7）、命中。目标：单场（Lv4，满资源）elite 区间 [0.75, 0.90]；在主线连续流程里，D1 的失败次数不超过总失败的 1/3。
2. **模拟策略**：敌人有 holy 弱点时，elite 战也允许使用圣水（只要背包里还剩 1 瓶以上留给需要的 Boss）。这是贴近真实玩家的行为。在报告里说明这一改动对结果的影响。
3. D2b（溶岩ドレイク）：同样按 elite 区间微调。
4. **イグニス、史莱姆王不动**。泉边休息引来史莱姆是有意的代价。
5. **目标**：hp70 策略下，主线每个职业的通关率 [0.55, 0.90]，职业差距 ≤ 0.25。如果只调 D1/D2b 达不到，就在汇报里说明还差多少、卡在哪里，**不要去改别的遭遇**。

## 验收
两条验证命令通过；报告 `eval/reports/balance-<日期>-ch34c.md`：前后对比、失败点分布、每处改动的原值 → 新值。
