# 033 城塞都市オークスドーン（第一步）：地下水路、城塞、聖騎士リーゼ

总体设计见 `docs/design/oaksdawn-v1.md`。本 spec 只做第 6 节的 033 一行。两份剧本始终同步修改。日文为定稿文本，照抄。

## 1. 入口：封印の洞窟の地下水路
- `cave_hot_spring` 新选项「湯の流れを辿る」（preview 空），去新地点 `cave_waterway`。
- **`cave_waterway`「地底の水路」**：温泉の湯は細い水路となって、岩の奥へ流れていく。水音を頼りに進むと、壁に古い騎士団の紋章――樫の葉と昇る太陽――が刻まれていた。
  - 选项：水路の先へ進む（→ `oaksdawn_water_gate`）／温泉へ戻る
- 洞窟地图加节点「地底の水路」（x 75, y 90，从「地底の温泉」连过去）。

## 2. 城塞の地点
**`oaksdawn_water_gate`「オークスドーンの水門」**
- 描述：水路の出口は、鉄格子の水門で塞がれていた。格子の向こうから、鎧の擦れる音と誰何の声が響く。「止まれ！ 何者だ！」
- 选项：
  - 名乗って門を開けてもらう：見張りの兵士は松明を掲げてこちらの顔を確かめると、渋々と格子を上げた。「森から水路を抜けてきただと……？ 団長に報告しておく。中へ入れ」 → `oaksdawn_square`
  - 水路を戻る（→ `cave_waterway`）
- 第一次开门后，之后经过水门不需要再名乗る（直接显示「城塞へ入る」／「水路へ戻る」）。

**`oaksdawn_square`「城塞の大通り」**（中心）
- 描述：石畳の大通りの両側に、樫の木を組んだ兵舎と工房が並ぶ。城壁の上では、白い外套の守護団員たちが東の峠を見張っていた。大通りの突き当たりには、昇る太陽を掲げた本営の旗がはためいている。
- 选项：守護団本営へ向かう／暁の礼拝堂へ向かう／城塞工房へ向かう／樫の葉亭へ向かう／城壁の見張り台へ上る／水門へ向かう

**`oaksdawn_hq`「守護団本営」**（NPC ヴァルター）
- 描述：地図と剣が並ぶ質素な広間。白髪の老騎士――守護団長ヴァルターが、卓上の地図から顔を上げた。
- 选项：
  - 団長に挨拶する（一次）：「森の水路を抜けてきたとは、物好きな冒険者だ。わしはヴァルター、暁の守護団の団長をしておる。……邪竜を討ちに行くのか。ならば一つ忠告しておこう。竜の谷の炎が本当にあの紅竜だけのものか、よく確かめることだ」
  - 十年前の遠征について聞く（挨拶后出现，一次）：「十年前、将軍ドラコは竜の谷への出兵を命じた。我ら守護団は盟約を理由にそれを拒み、それ以来、王都からは見捨てられた砦よ。あの時に谷へ向かった兵は、一人も帰ってこなかった」 → `heard_guardian_refusal`，加进凱旋の間「将軍ドラコの正体を問いただす」的线索列表。
  - 推薦状を願い出る（听过十年前的事后出现，一次）：ヴァルターは羽根ペンを走らせ、封蝋を押した。「礼拝堂のリーゼに見せるといい。あの子は古戦場の鐘のことで、ずっと胸を痛めておる」 → 得到「守護団の推薦状」（key 道具，说明：暁の守護団長ヴァルターの署名入りの推薦状。）
  - 大通りへ戻る

**`oaksdawn_chapel`「暁の礼拝堂」**（NPC リーゼ）
- 描述：高い窓から朝の光が差し込む礼拝堂。祭壇の前で、銀の鎧をまとった若い女騎士が祈りを捧げている。
- 选项：
  - 祈りを捧げてもらう（5G，全回复）：祭壇の前で目を閉じると、温かな光が体を包み、疲れが消えていった。
  - 女騎士に話しかける（一次）：「私はリーゼ。暁の守護団の聖騎士です。……南の古戦場から、夜ごと弔いの鐘が聞こえるのです。死者がまだ眠れずにいる。いつか、確かめに行かなければ」 → `met_liese`
  - 以下三项在 `met_liese` 后出现，任一成功即加入，加入后三项都隐藏：
    - 守護団の推薦状を見せる（持有推薦状）：リーゼは推薦状の封蝋を確かめ、静かに頷いた。「団長がお認めになったのなら、私もこの剣を預けましょう」
    - 聖水を祭壇に捧げる（持有聖水，消耗 1）：祭壇に聖水を注ぐと、リーゼは目を見開いた。「死者を弔う心をお持ちなのですね。……ご一緒させてください」
    - 共に死者を弔いたいと説く（1d20+wis，DC13，一次）：成功「……その言葉、信じます。ご一緒させてください」／失败「お気持ちは嬉しいのですが、私は守護団の務めを離れられません」
  - 聖水を分けてもらう（商店：聖水 12G）
  - 大通りへ戻る

**`oaksdawn_workshop`「城塞工房」**（NPC ブリギッテ）
- 描述：炉の熱と槌の音が響く工房。分厚い前掛けの女鍛冶師が、白銀の剣に光の紋を刻んでいる。
- 选项：
  - 鍛冶師に話しかける（一次）：「守護団の鎧なら、いくらでも打ってやるよ。光の紋を刻んだ武器は……材料が揃ったら、また来な」（034 的伏笔）
  - 店に入る（商店：守護団の鎖帷子，40G，防具部位，被ダメージ −2，说明：守護団員が身につける、目の細かい鎖帷子。）
  - 大通りへ戻る

**`oaksdawn_inn`「樫の葉亭」**
- 描述：樫の梁がむき出しの酒場兼宿屋。非番の守護団員たちが、干し肉をかじりながら峠の噂話をしている。
- 选项：
  - 宿で休む（10G，全回复）：樫の香りのする寝台で、久しぶりにぐっすりと眠った。
  - 噂話を聞く（一次）：「東の峠が、季節外れの霜で閉ざされちまった。夜中に、白くてでかい影が谷の方へ飛んでいくのを見たって奴もいる」 → `heard_pass_rumor`，同样加进凱旋の間的线索列表。
  - 大通りへ戻る

**`oaksdawn_wall`「城壁の見張り台」**
- 描述：城壁の上からは、南に霧の古戦場、東に白く凍りついた峠が見渡せる。
- 选项：
  - 城塞の街道を南へ下る：城門を出て街道を南へ下ると、やがて白い霧が足元から立ちのぼってきた。→ `old_battlefield`
  - 東の峠へ向かう：本 spec 里不可选，原因「峠は霜で閉ざされていて、今は通れない。」（属于「已知但不可选」，显示原文）
  - 大通りへ戻る
- 反向：`old_battlefield` 新选项「城塞の街道を北へ向かう」（→ `oaksdawn_square`），到过城塞以前按 030 的规则风险显示「不明」。

## 4. 聖騎士リーゼ（同行者）
- `id: paladin_liese`，名称「聖騎士リーゼ」，立绘 `npc_liese`。
- 说明文：暁の守護団の若き聖騎士。毎ラウンド開始時、プレイヤーのHPが半分未満なら「癒しの祈り」で最大HPの20%を回復し、そうでなければ「聖光の一撃」で敵へ2d6の光属性ダメージを与える（不死の敵を優先して狙う）。
- 引擎需要的通用能力（不要写成リーゼ专用）：
  - `round_start_effects` 的条件：按玩家当前 HP 比例（`player_hp_ratio_lt` / `player_hp_ratio_gte`）。两条效果每回合只触发一条。
  - 目标选择 `"target": "undead_first"`：优先选带 `undead` 标签的存活敌人（其中 HP 最高者），没有就退回 `highest_hp`。
  - 光属性用现有的 `holy` 元素（日志里写「光属性」）。
- 招募时的 preview：同行者にする（HPが半分を切ると回復、それ以外は光の一撃）。

## 5. 不死系
骸骨兵、屍鬼、怨霊、墓守の骸骨騎士、煤の亡霊、Xanxusの分身、亡霊主宰ゼボク：加 `tags: ["undead"]`，`holy` 抗性统一为 1.5（煤の亡霊 1.4 → 1.5）。其他属性不变。

## 6. 平衡（只调リーゼ自己的数值：回复比例、伤害骰）
- 古戦場三场战斗（无诅咒）：带リーゼ比不带，平均 HP 损失减少 ≥ 30%，骑士战胜率 +10pp 以上（已到 100% 上限的职业除外）。
- 古戦場以外（森、村、竜の谷、最终战）：リーゼ的贡献不超过现有同行者里最强的那个 +3pp。
- 报告 `eval/reports/balance-2026-10-17-liese.md`。达不到时说明，不要改现有敌人或其他同行者。
