# 032 装备部位制、防具价格、ロビンの援護射撃の対象

来源：用户试玩反馈（2026-10-15）。现在所有防具都能叠加，勇者开局买一件鎧就能叠出很高的减伤，太无脑。两份剧本始终同步修改。

## 1. 装备部位
每件可装备的道具加 `slot` 字段，三个部位各只能装一件。**不按 combat.kind 推断**（`equipment` 类型里混着杖、书、ローブ和护符）。

| slot | 道具 |
|---|---|
| `weapon` | 所有 `kind: weapon` 的道具；聖なる杖；魔導書 |
| `armor` | 革の鎧（勇者、盗賊两种）；ローブ；魔法のローブ；アダマンタイトの鎧；墓守の外套 |
| `accessory` | 氷の護符(活性化済)；紅玉の護符；呪われた水晶球；暗黒の水晶球 |

- 角色初始背包里的道具（`characters[].inventory`）同样要加 `slot`。
- 没有 slot 的道具（未活性化的氷の護符、縮小の銃、霜封じの護符等）不能装备，也不显示「装備中」；它们照旧在战斗的道具菜单里使用，或作为持有即生效的道具。
- **规则**：装备新道具时，同一部位原来的道具自动卸下。所有装备入口都走这条规则：背包「装備する」、`equip_on_buy`、剧情效果 `equip_item`（鍛冶師の剣、ローベルトの鎧、呪いの品、虹晶の武器等）。
- 卸下的道具留在背包里，不生效（确认 `_actor_defense`、`equipped_item_specs` 等所有读装备效果的地方都只算已装备的）。
- 系统日志：「革の鎧を外し、アダマンタイトの鎧を装備した。」；部位原本为空时沿用「◯◯を装備した。」。
- **旧存档**：读档时某部位有多件已装备，只保留列表里最后一件（最近装备的），其余卸下。
- 客户端背包：装备类道具在名称旁显示部位标签（武器 / 防具 / 装飾品）；同部位已有装备时按钮写「装備する（◯◯と入れ替え）」。只用现有样式变量。

## 2. 价格
- `forge_shop` 的アダマンタイトの鎧：20G → **60G**。开局 100G 要在它和氷の護符（50G）之间取舍。其他价格不变。

## 3. ロビンの援護射撃
设计侧已改好数据（`scripts/scenario/design_031.py` 的 `COMPANIONS`）：伤害 `2d4+1`，`"target": "highest_hp"`。引擎需要支持这个通用目标选择：在存活的敌人中选当前 HP 最高者，同值取列表中靠前的一个；`random_target` 的现有行为不变。跑 `python -m scripts.scenario.design_031` 写入两份剧本（031 的迁移脚本也会调用它，保持幂等）。

## 4. 平衡
重跑现行的平衡报告（职业路线、最终战、031 的奖励复核），和上一份对比，写 `eval/reports/balance-2026-10-15-slots.md`。原因要分开列：部位制、鎧の価格、ロビン各自的影响。任何目标偏离超过 5pp 时如实报告，**不要调数值**，由设计负责人决定。
