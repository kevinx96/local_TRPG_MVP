### 3.2 L2 敌人伤害与 HP（M9 带宽）
- **方向（用户要求 normal 敌人更狠）**：低于下限的遭遇，抬到带内上半段；高于上限的遭遇，只降到上限，不压进下半段。
- 单次期望伤害按 G1 的公式反推：≈ 带宽目标 × P2 中位等级最大 HP ÷（1 − 该职业平均闪避）；骰子用低方差写法（例如 `2d4+k` 而不是 `1d21`），CV ≤ 0.5。命中不用调（normal 的敌方命中已统一为 100）。
- HP 允许 ×0.6–1.5 基础值；防御 ±2。Boss HP 同时满足 M4 ≤ 14（P2 / heuristic_v3）和 `targets.classes.boss.rounds` 7–12。
- 重点：`goblin_fort_fourth`（F1，Lv2 Boss，0.49–0.65 → ≤ 0.35）、`goblin_fort_first_second`（elite 0.26–0.55）、`dark_forest_loc`（Lv1 trash 0.40–0.67，先确认是不是脚本化的开场伏击）、三条洞窟 elite（Lv3–4，0.25–0.41）、`valley_entrance`（F2，0.87–0.91）。低于下限的主线 Boss（スライム王 0.09–0.14、氷霜の巨狼 0.07–0.09、Ignis 0.12–0.14）在 a 段抬到带内；Ignis、虹晶樹、ドラコ 的结构性改动留给 b 段。
- 不改：`scripted_loss`、`guest` 遭遇；敌人的种类、技能名、剧情含义（G 节）。
- `encounter_class` 为空的 29 个遭遇不进 M9；要不要补分类见 Q6。

### 3.3 L3 G2 百分比招式与蓄力预告（052b，需要引擎）
引擎现在没有"按玩家最大 HP 比例"的敌方攻击，也没有蓄力预告；有 `every_n_rounds`、`use_below_hp_ratio`、`ai_weight`、`max_uses_per_battle`。新增（全部数据驱动，字段不存在时行为与现在逐字节一致）：

| 字段 / 规则 | 内容 |
|---|---|
| `damage_max_hp_ratio` | 伤害 = 玩家当前最大 HP × 比例（取整）；**无视平坦防御**；受防御姿态、`received_damage_multiplier`、护盾影响；**可以被闪避**；元素抗性道具有效（紅玉の護符 对火属性的有效） |
| `telegraph` | `{"charge_rounds": 1, "warning": "【仮】…"}`：选中时本回合只写预告日志（沿用现有日志类型），下一回合放出；蓄力中被眩晕 / 打断则取消（如果有打断手段） |
| 同回合合计上限 | 多名精英同一回合的百分比伤害合计 ≤ 玩家最大 HP 的 30%（常量放 `combat_rules`，经 `MECHANIC_FIELDS`） |
| 気絶 | 只允许挂在百分比招式或预告招式上（skills-v2 第 6 节） |

| 数据 | 范围 |
|---|---|
| 每个 elite | **恰好 1 个**百分比招式，15–25%；触发用 `ai_weight` 约 1/3 或 `every_n_rounds: 3`（二选一） |
| Boss | 最多 1 个带预告的大招，30–45%；P2 的应对手段要能压到 ≤ 20% |
| trash | 不设 |
