# 021 第 3、4 章的设计修正（019 的 TODO(design)）

设计负责人对 019 汇报里的 TODO 作出以下决定。日语正文逐字使用，两份剧本同步修改。

1. **「ワーロックの名を呼ぶ」的条件**：原来写的是 `warlock_rescue_triggered`，但它和 `accepted_fire_seed` 在正常流程里互斥（服从才拿到火种，拒绝才会被救）。这是设计文档的错误。条件改为 `warlock_rescue_available`（在魔法店邀请过ワーロック）。剧情上，他在村子里消失以后一直在暗中守护（イグニス战后他说过「私は背後から見守っています」，可以对上）。
   - "没有火种、但和ワーロック有交情的玩家看到短暂现身"的条件，也同样改成 `warlock_rescue_available`。
2. **净化火种的文字**改为（替换 chapter3-4-v4 2.3 中 `cleanse_fire_seed` 的结果文）：
   「聖なる光が胸の火種を包み込み、その炎が弱まっていく。Xanxusが怒りに吠える。『小癪な……火種を消される前に、力ずくで奪うまでだ！』」
   火种只在分身战胜利后才移除（和现在的实现一致）。
3. **Lv5 里程碑**：从 D1（进谷）改到 **D3（竜の巣の前）** 第一次到达时触发；Xanxus 事件在升级**之后**发生。`entered_dragon_valley` 仍然在 D1 设置（任务和线索用）。这样谷口和吊桥的消耗由玩家自己承担，イグニス战开始时资源是满的。
4. **连续流程的评价策略**：主线目标（[0.55, 0.90]）改为在"会使用付费休息"的策略下评价：可以休息的地方（宿屋 10G、避难所 5G、泉、温泉），在 HP < 70% 并且金币足够时休息。"完全不休息"的结果照常报告，但只作参考，不判定。`route.py` 加上这个策略，报告两种结果。
5. D1（煤の亡霊）的盗贼胜率 93.8%，超出 elite 上限：在 005 允许的范围内微调。

## 验收
