# 007 数值第三轮：模拟策略、连续流程、文本同步

依据：`eval/reports/balance-2026-10-11-pass2.md` 第 6、9 节。设计负责人的决定如下。

## 1. 目标修订（已改好 `eval/balance/targets.json`）
- trash：`hp_left` [0.60, 0.95]，`rounds` [1, 4]
- elite：`hp_left` [0.35, 0.70]
- boss：`hp_left` [0.15, 0.50]
- 新增 `encounter_overrides`：merchant_battle 的 `rounds` [2, 5]、`hp_left` [0.50, 1.00]，胜率目标不变
- 同伴提升：按有同伴的 cell 等权平均验收，不要求每场都达标
- 请让 `--check` 读取 `encounter_overrides`，并写测试。

## 2. 模拟策略：保留稀有消耗品
heuristic 和 greedy 都不能在 trash/elite 战里使用"稀有消耗品"。稀有的定义：圣属性物品，或者任何一次伤害期望 ≥ 敌人最大 HP 30% 的消耗品，或者剧本里标了 `rare: true` 的物品（如有需要，在 schema 里加这个可选字段，并给聖水和各种巻物标上）。Boss 战可以用。报告里单列每场战斗的消耗品使用情况。

## 3. 连续流程模拟（新功能）
- `scripts/balance/route.py`：按 checkpoint 的路线顺序依次进行战斗，资源**不在战斗之间回满**。只在以下时机恢复：剧本里明确回复的动作（宿屋、回复阵、泉）、以及升级。消耗品跨战斗计算。战败即这条路线失败（剧情必败战除外，按剧本效果继续）。
- 输出每个职业的：通关率、在哪场战斗失败的分布、到达最终 Boss 时的平均资源。
- 这次只报告，不设阈值。

## 4. 技能重名（设计负责人的失误，按下面修正）
新技能和旧技能重名的（渾身斬り、影隠れ、火球、氷の矢、急所突き），改为**升级**：达到解锁等级时，用新数值**替换**同名的旧技能，名字加上「・改」（例如「渾身斬り・改」）。旧技能本来没有、真正新增的技能（不屈の構え、聖なる裁き、大いなる癒し）照常追加。
- 魔法使的范围攻击（火球・改，或者没有旧版时就是火球）提前到 **Lv2** 解锁，以便在砦的多敌人战斗里用得上。如果按路线顺序，砦战发生在 Lv2 触发之前，在汇报里说明，不要自行改触发条件。

## 5. 旧存档的技能补发
加载存档时，如果角色等级 ≥ 某个技能的解锁等级、身上却没有这个技能，就补发。例外：存档的事件记录里，在该里程碑之后出现过 `clear_skills` 这类剧情效果时，不补发。写测试。

## 6. 文本同步（只允许以下改动）

- 004/005 改过敌人数量的遭遇：地点描述或结果文本里如果有具体数字（例如「5匹」），改成和新数量一致。只改数字和量词，不改其他文字。列出所有改动。
- 没有具体数字、但读起来和新数量矛盾的句子，列出来标 `TODO(design)`，不要改。
