# 035 第三章可选地图「地鳴りの峡谷」与水術士エリオ

总体设计见 `docs/design/oaksdawn-v1.md` 第 5 节。和霧の古戦場一样是可选路线：オークスドーン → 峡谷 → 麓の村の避難所（`village`）の裏手，汇入主线。两份剧本始终同步修改。日文为定稿文本，照抄。

## 1. 开通东の峠
- `oaksdawn_hq` 新选项「東の峠を通りたいと頼む」（`greeted_walter` 后出现，一次）：「峠を越えるだと？ ……いいだろう、守護団員に岩をどけさせよう。だが峡谷には近ごろ、岩でできた獣が出るそうだ。気をつけて行け」→ `gorge_path_open`。
- `oaksdawn_wall` 的「東の峠へ向かう」在 `gorge_path_open` 后可选（未开通时沿用 033 的不可选原因），去 `gorge_entrance`。叙述：守護団員たちがどけた岩の間を抜け、東の峠へ踏み込んだ。
- `oaksdawn_wall` 的描述加变体（`gorge_path_open` 后）：城壁の上からは、南に霧の古戦場、東に岩肌のむき出しになった峠が見渡せる。峠の大岩はどけられ、細い道が東へ続いている。

## 2. 地点
**`gorge_entrance`「峡谷の入口」**
- 描述：守護団員がどけた岩の向こうに、深い峡谷が口を開けていた。足元が低く唸るように揺れ、岩壁から小石がぱらぱらと落ちてくる。
- 选项：落石の道を進む ／ 城塞へ戻る（→ `oaksdawn_wall`）

**`gorge_rockfall_path`「落石の道」**（普通战：砂礫の甲虫 ×2）
- 描述：崩れた岩が転がる細い道。岩陰から、砂利を固めたような甲虫が二匹、顎を鳴らして這い出してきた。
- 选项：
  - 甲虫と戦う。开战：剣を構えると、甲虫たちは殻を擦り合わせて威嚇しながら、じりじりと間合いを詰めてきた。
  - 岩陰を縫って抜ける（1d20+dex、DC13）。成功：甲虫が砂利を噛んでいる隙に、岩陰を縫って道を抜けた。失败：足元の小石が崩れ、甲虫が一斉にこちらを向いた。→ 开战
- 胜利：甲虫は殻ごと崩れて、ただの砂利の山に戻った。
- 通过后：鉱夫の野営跡へ向かう ／ 白い爪痕の崖へ向かう ／ 峡谷の入口へ戻る

**`gorge_miner_camp`「鉱夫の野営跡」**
- 描述：崩れかけた天幕と、冷えた竈が残る野営跡。逃げ出した鉱夫たちの道具が、そのまま散らばっている。
- 选项：
  - 竈に火を入れて休む（一次，全回复）：竈に火を入れて、天幕の陰で短く眠った。地鳴りが、遠くで低く続いている。
  - 鉱夫の荷物を調べる（一次）：散らばった荷物の中から、携帯食と一冊の日記が出てきた。最後の頁には、震える字でこう書かれている。「……昨夜、峠の上を白いものが飛んでいった。その直後に山が崩れた。あれは竜だ。白い竜だ」→ 携帯食 ×2，`read_miner_diary`（加进凱旋の間的线索列表）
  - 落石の道へ戻る

**`gorge_claw_cliff`「白い爪痕の崖」**
- 描述：峠をふさいでいた崩落の跡。巨大な岩の断面に、何かが引き裂いたような爪痕が三本、深く刻まれている。
- 选项：
  - 爪痕を調べる（一次）：爪痕の奥には、真夏でも溶けない白い霜がこびりついていた。この岩は、山崩れで落ちたのではない。何か巨大なものが、爪で引き裂いたのだ。→ `saw_white_claw`（加进线索列表）
  - 岩の巨人の通り道へ進む ／ 落石の道へ戻る

**`gorge_giant_path`「岩の巨人の通り道」**（精英战：岩の巨人 ×1、石肌のトカゲ ×1）
- 描述：峡谷が狭まる先で、苔むした岩山がゆっくりと立ち上がった。岩の巨人だ。足元では、石肌のトカゲが舌を鳴らしている。
- 选项：
  - 岩の巨人と戦う。开战：岩の巨人が腕を振り上げると、峡谷全体が低く鳴った。トカゲが岩陰から跳び出してくる。
  - 巨人の足元をくぐり抜ける（1d20+dex、DC15；成功可按 031 的规则偷取该区域的果实）。成功：巨人が腕を振り上げた隙に、足の間を転がるようにくぐり抜けた。失败：巨人の踵が地面を打ち、揺れに足を取られた。→ 开战（敌人先手）
- 胜利：岩の巨人は崩れて、ただの岩山に戻った。崩れた胸の奥に、赤い果実が一つ埋まっている。
- 通过后：峡谷の底へ下りる ／ 白い爪痕の崖へ戻る

**`gorge_worm_lair`「峡谷の底」**（Boss：土喰らいの大ワーム）
- 描述：峡谷の底は、無数の穴で蜂の巣のようになっていた。地鳴りがひときわ大きくなり、地面を突き破って巨大なワームが姿を現す。
- 选项：
  - 大ワームと戦う。开战：大ワームが鎌首をもたげ、土砂を噴き上げながら襲いかかってきた。
  - 地鳴りの合間を縫って駆け抜ける（1d20+dex、DC17）。成功：揺れが途切れた一瞬に、巣穴の間を一気に駆け抜けた。失败：足元の地面が崩れ、ワームの巣穴へ滑り落ちた。→ 开战（敌人先手）
  - エリオの水で巣穴を満たす（**エリオ在队时才显示**，判定不要，不战斗、不掉落）：エリオが杖を掲げると、峡谷の湧き水が渦を巻いて巣穴へ流れ込んだ。地中で何かが苦しげにのたうち、地鳴りが遠ざかっていく。「今のうちだ、行こう！」
- 胜利：大ワームは身をよじり、地響きとともに崩れ落ちた。あれほど続いていた地鳴りが、ふっと止んだ。→ 鉄壁の霊薬 ×1、金币按 031 的经济规则
- 通过后：峡谷を抜けて村へ下る → `village`，叙述：峡谷を抜けると、眼下に麓の村が見えた。焼け跡の残る家々の外れ、避難所の裏手へと細い坂道が続いている。

## 5. 水術士エリオ（同行者）
- NPC：`oaksdawn_inn`（樫の葉亭）。描述变体（未加入时）：樫の梁がむき出しの酒場兼宿屋。非番の守護団員たちが峠の噂話をする隅で、青い外套の青年が水差しの水面をじっと見つめている。
- 「青い外套の青年に話しかける」（一次）：「やあ。僕はエリオ、流れの水術士さ。東の峡谷の地鳴りを調べに来たんだけど、道が塞がれていてね。……君も峠を越えるつもりかい？」→ `met_elio`
- 加入（`met_elio` 后，三选一，加入后隐藏）：
  - 傭兵として雇う（50G）：「契約成立だね。水の届くところなら、どこでも役に立ってみせるよ」
  - 精霊の泉の水を渡す（持有「精霊の泉の水」，消耗）：エリオは水差しの水を光にかざし、目を輝かせた。「精霊の泉の水だ……！ こんなものをもらったら、断れないよ。一緒に行こう」
  - 地鳴りの謎を一緒に調べようと誘う（1d20+int、DC13，一次）：成功「……面白い。君となら、あの地鳴りの正体に辿り着けそうだ」／失败「悪いけど、僕はひとりで調べる方が性に合っていてね」
- 「精霊の泉の水」：`elf_spring` 新选项「泉の水を汲む」（一次）：澄んだ泉の水を、空の水筒に汲んだ。水面が、ほのかに光っている。说明文：精霊の泉で汲んだ澄んだ水。ほのかに光を帯びている。
- 同行者 `hydromancer_elio`，名称「水術士エリオ」，立绘 `npc_elio`。说明文：流れの水術士。毎ラウンド開始時に「水刃」で敵へ2d4の水属性ダメージを与える（水に弱い敵を優先して狙う）。3ラウンドごとに「水の帳」を張り、そのラウンドにプレイヤーが受けるダメージを半分にする。
- 招募 preview：同行者にする（毎ラウンド水の刃、3ラウンドごとに被ダメージ半減）
- 引擎需要的通用能力（不要写成エリオ专用）：目标选择「优先选对某属性弱的敌人」（例 `"target": "weak_to:water"`，没有则退回 `highest_hp`）；回合效果「本回合玩家受到的伤害 ×0.5」。
- 峡谷のワーム的绕过选项依赖エリオ在队（第 2 节）。

## 6. 平衡（只调新敌人、新 DC、エリオ自己的数值）
- 起点：森の出口／オークスドーン可达的检查点，4 职业。
- **不带エリオ**：从 `gorge_entrance` 走到 `village` 的成功率，与村子路线（`village_approach` → `village_frozen_clue`）相差 ±5pp 以内。
- **带エリオ**：峡谷三场战斗平均 HP 损失减少 ≥ 30%，或 Boss 战胜率 +10pp 以上（已到上限的职业除外）。
- 峡谷以外：エリオ的贡献不超过现有同行者里最强的那个 +3pp。
- 报告 `eval/reports/balance-2026-10-18-gorge.md`。达不到时说明，不改现有敌人或其他同行者。
