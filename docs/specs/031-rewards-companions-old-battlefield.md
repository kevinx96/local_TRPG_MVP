### 1.3 平衡检查（只报告，不改上面的数值）
重跑平衡模拟，分两种玩家：「主线」（只打主干上躲不开的战斗）和「全探索」（打所有可选战斗、拿全部掉落）。报告最终两场（イグニス、ドラコ / ヴァイス）的胜率和上一份报告的差。超过以下范围时**停下来汇报**，由设计负责人决定是否改成 +1 / +3：主线 ≤ +5pp，全探索 ≤ +15pp。

## 2. 非主线战斗不能是负收益
现在洞窟、谷の岩棚、屋敷、宿屋の襲撃等很多可选战斗给 0 金币、没有道具。
- **定义**：一场战斗的期望成本 = 消耗品（按商店买价）+ 损失的 HP / MP 折算成休息费（该章可用的最便宜休息价格 ÷ 该章检查点的最大 HP / MP，再乘以损失量）。期望收益 = 金币 + 掉落道具（按商店买价；永久道具不计入）。
- **目标**：每场非主线战斗的期望收益 ≥ 期望成本 × 1.3。只调整**金币和普通消耗品**掉落（薬草、MP回復薬、聖水、治療の巻物、煙玉等现有道具），不改敌人强度。
- 报告 `eval/reports/battle-economy-2026-10-13.md`：每场战斗的成本、收益（改前 / 改后）。

## 3. 同伴特长
### 3.1 ロビンの罠（ゴブリン王）
ロビン在队时，`goblin_fort_fourth` 战斗开始时ゴブリン王**眩晕 2 回合**（不行动）。引擎没有眩晕机制就加一个通用的遭遇修正（`enemy_skip_rounds` 之类），不要写成ゴブリン王专用。
- 开战文本：「足元、気をつけな」ロビンが金貨の山の陰に仕掛けておいた投げ縄が跳ね上がり、ゴブリン王の足をすくった。王は金貨の山に頭から突っ込み、目を回している。
- 恢复时的日志：ゴブリン王が頭を振りながら起き上がった。

### 3.2 火コウモリ竜の強化（虹晶樹）
火コウモリ竜在队时打倒虹晶樹，设置 `fire_bat_empowered`，之后它每回合的回复从 3 变为 **6**（伤害不变）。
- 胜利后追加文本：砕け散った虹晶の欠片を、火コウモリ竜が嬉しそうについばんだ。小さな炎が、虹色にきらめいている。
- 同伴说明改为：毎ラウンド開始時に敵へ2d3の火属性ダメージを与え、プレイヤーのHPを3回復する（虹晶を食べた後は6回復）。

### 4.3 「诅咒持有者」和ワーロック
- **诅咒持有者** = 背包里有 呪われた聖剣 / 聖杖 / 水晶球 / 短剣 中的任意一件。
- 在这张地图上：诅咒持有者明显更容易（亡者认出ゼボク的印记），没有的人遭遇更难的战斗。具体见各地点。
- **ワーロック**：这张地图上他的回复不生效（瘴気で元素の流れが乱れる）。
- **圣属性**：这张地图的亡者全部弱圣属性（×1.5）。将军「不死の者には聖水が効く」的提示在这里兑现，僧侶的圣魔法也在这里最强。

### 4.4 地点
**`old_battlefield`「霧の古戦場」**
- 描述：森を抜けた先で、街道は白い霧に沈んでいた。草むらには錆びた剣と兜が転がり、折れた軍旗が風に鳴っている。どこか遠くで、弔いの鐘が一度だけ鳴った。
- 进场追加（ワーロック在队）：ワーロックが足を止めた。「瘴気が濃い……ここでは元素の流れが乱れる。癒やしの術は当てにしないでくれ」
- 进场追加（诅咒持有者）：腰の呪いの品が、かすかに脈打った。霧の向こうで、何かがこちらを見ている。
- 选项：骨の野へ進む ／ 森の出口へ戻る

**`bone_field`「骨の野」**（普通战：骸骨兵 ×2）
- 描述：霧の中から、錆びた鎧をまとった骸骨の兵士が二体、ぎこちなく立ち上がった。
- 选项：
  - 骸骨兵と戦う（危険（戦闘））
  - 霧に紛れて抜ける（1d20+dex、DC14）。成功：骸骨兵が霧の向こうを見つめている隙に、野を抜けた。失败：足元の骨が乾いた音を立て、骸骨兵が一斉にこちらを向いた。→ 开战
  - 呪いの品を掲げて通る（**只对诅咒持有者显示**，判定不要）：骸骨兵は呪いの品の気配に気づくと、錆びた剣を下ろして道を開けた。
- 胜利：骸骨兵は崩れ落ち、ただの骨の山に戻った。
- 通过后：崩れた見張り塔へ向かう ／ 屍鬼の沼へ進む ／ 霧の古戦場へ戻る

**`ruined_watchtower`「崩れた見張り塔」**
- 描述：半ば崩れた石の塔。中では、半透明の兵士が一人、消えた焚き火の前にうずくまっている。
- 选项：
  - 亡霊の兵士に話しかける：亡霊は顔を上げた。「……十年前、将軍ドラコの進言で、我らは竜の谷へ送られた。谷に着いた夜、白い霜が陣を覆い、気づけば皆ここで骨になっていた。紅竜の炎ではない。あれは、ひどく冷たかった」 → 设置 `heard_old_soldier_ghost`，并加进凱旋の間「将軍ドラコの正体を問いただす」的线索列表（`flags_count_gte` 的 flags）。
  - 塔の上を調べる（判定不要，一次）：崩れた階段の上に、古い衛兵の外套が残っていた。裏地には、死者を鎮める祈りの文句が縫い込まれている。→ 得到「墓守の外套」（防具，被ダメージ −2；对这张地图的亡者再 −1）。
  - 焚き火に火を入れて休む（判定不要，一次，全回复）：消えた焚き火に火を入れ、少しだけ休んだ。亡霊は黙って、その火を見つめていた。
  - 骨の野へ戻る

**`ghoul_marsh`「屍鬼の沼」**（精英战：屍鬼 ×1；**非**诅咒持有者时再加 怨霊 ×1）
- 描述：黒い水が淀む沼地。泥の中から、腐った腕が何本も突き出している。
- 开战追加（诅咒持有者）：屍鬼は呪いの品の気配に怯え、動きが鈍っている。→ 屍鬼 HP ×0.6
- 开战追加（非持有者）：沼の上に青白い怨霊が浮かび上がり、屍鬼に加勢した。
- 选项：屍鬼と戦う ／ 沼の縁を伝って抜ける（1d20+dex、DC15；成功可偷魔力の果実，见 1.2）／ 骨の野へ戻る
- 胜利：最後の屍鬼が泥の中へ沈んだ。黒い水面に、青く光る果実が一つ浮かんでいる。

**`grave_chapel`「墓守の礼拝堂」**（Boss：墓守の骸骨騎士）
- 描述：古戦場の外れに、屋根の落ちた小さな礼拝堂がある。祭壇の前で、大剣を携えた骸骨の騎士が膝をついている。
- **ゼボク登场**（第一次进入时，按状态四选一，作为进场叙述）：
  - 诅咒持有者、还没付代价（`curse_bargain_pending` 且非 `curse_price_paid`）：祭壇の陰から、聞き覚えのある笑い声がした。黒いローブの小柄な商人――ゼボクが、毛むくじゃらの指で骸骨の騎士の兜を撫でている。「おや、我が品を大事にしているようだな。骨どもも、主の匂いには逆らえん。……代価のことは、忘れておらぬぞ」商人の姿は、霧に溶けるように消えた。
  - 诅咒持有者、已付代价：「代価は確かに受け取った。客人には道を開けてやれ」ゼボクが手を振ると、骸骨の騎士は静かに頭を垂れた。商人の姿は、霧に溶けるように消えた。
  - 在夜の路地反悔并与他战斗过：「懲りぬ奴よ。あの夜の借りは、この騎士に返してもらおう」ゼボクの指が鳴ると、骸骨の騎士の眼窩に赤い火が灯った。商人の姿は、霧に溶けるように消えた。→ 骑士先手
  - 以上都不是：祭壇の陰に、毛むくじゃらの小柄な影が見えた。「人の子か。ここは死者の道……生者が通る道ではないぞ」影は喉の奥で笑い、霧の中へ消えた。
- 选项：
  - 诅咒持有者：騎士に道を譲ってもらう（判定不要，不战斗、不掉落）：骸骨の騎士は大剣を床に突き立て、深く頭を垂れた。祭壇の脇の裏門が、軋みながら開く。／ あえて騎士に挑む（正常强度的 Boss 战）
  - 非持有者：骸骨の騎士と戦う（不能跳过）
- 胜利：骸骨の騎士は、大剣を祭壇に立てかけるように崩れ落ちた。兜の奥から、赤い果実が二つ転がり出た。
- 之后：礼拝堂の裏門から村へ抜ける → `village_frozen_clue`，叙述：礼拝堂の裏門を抜けると、坂の下に炎上する麓の村が見えた。村の外れの一角だけが、なぜか白く凍りついている。

### 4.6 难度目标（用平衡模拟验证，在汇报里给数字）
起点用第 2 章结束（森の出口）的检查点，4 职业。
- **非诅咒持有者**：从 `old_battlefield` 走到 `village_frozen_clue` 的成功率，与从 `village_approach` 走到 `village_frozen_clue` 的成功率相差 ±5pp 以内。
- **诅咒持有者**：比非持有者高 15pp 以上。
- **ワーロック在队**的成功率提升 ≤ 3pp（在村子那条路上的提升作为对照一起报告）。
- 只调新敌人的数值和新地点的判定 DC；达不到时在汇报里说明，不要改现有敌人。
