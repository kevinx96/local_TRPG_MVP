# 036 全套道具图标

用户决定（2026-10-18）：所有道具都配图标（034 的方案 A）。034 已加可选 `icon` 字段并试点 7 张。

## 1. 范围
- 两份剧本 `items` 里的全部道具，加上角色初始背包里内联定义的道具（革の鎧、ローブ、魔導書等）。同名道具共用一张图标（例如两种革の鎧）。
- 035 新增的道具（精霊の泉の水等）也包括在内。
- 034 的 7 张试点图标保留，作为画风基准。

## 2. 画风和规格
- 和试点一致：厚涂、单个物体居中、透明背景、无文字、无边框，光源左上。正方形，**输出 128×128 PNG**（生成后缩到这个尺寸并做无损压缩）。
- 同类道具保持一致的视角和大小感：武器斜放、防具正面、药瓶 / 卷物 / 素材正面略俯视。
- 有剧情外观的道具照文本画：例如「呪われた聖剣」带黑紫色的诅咒纹路、「氷の護符(活性化済)」比普通氷の護符多一圈冷光、「アダマンタイトの鎧＋」等打ち直し后的防具和原版共用图标。
- 每项 1 张，不做候选对比；设计负责人看总览图后挑出要重画的，再由工程重画。

## 3. 显示位置
- 背包（034 已有）。
- 商店的商品列表（名称左侧，同样尺寸）。
- 战斗中的道具菜单（名称左侧）。
- 获得道具的通知里不加图标。
- 没有图标的道具保持现状；只用现有样式变量。

## 4. 交付
- `client/images/icon_<id>.png`，登记 `assets/manifest.json`（`approved: false`，由设计负责人批准）。
- 总览图 `eval/reports/screens/036/icons-sheet.png`：所有图标按类别排列，每个下面写道具名。
- 截图：背包、商店、战斗道具菜单各一张。
- 加测试：每个道具都有存在的图标文件；所有图标都是 128×128 并带透明通道；`client/images/icon_*.png` 总大小低于 2MB。

## 不做
- 不改道具数值和文本；不改提示词。

## 汇报
按 `docs/roles/engineering.md` 的格式；列出共用图标的道具组，以及生成时觉得不确定外观的道具（推断清单）。
