# 017 虹晶武器改为打弱点 + 目标调整 + "自称有证据"的提示词变体

## 1. 虹晶武器：自动打弱点
015 的数据：虹晶武器对イグニス战的提升只有 勇者 +3.8pp / 僧侣 +11.8pp / 魔法使 0pp / 盗贼 +1.6pp（目标 10–20pp）。原因推测：`counter` 属性选的是"克制目标主属性的元素"（火 → 水），但イグニス的弱点是冰。设计本意（forest-v3 2.5）是"自己找出对方的弱点"。
- 新增属性 `weakness`：攻击时，查目标的抗性表（包括道具带来的倍率），选倍率最高的属性；最高倍率 ≤ 1.0 时退回 `physical`。虹晶樹轮换颜色时，按当前的抗性组计算。
- 4 把虹晶武器改用 `weakness`，`counter` 的原有行为保持不变（其他物品可能还在用）。
- 重新测量：虹晶武器对イグニス战的提升（目标 10–20pp）；超出就降低武器伤害，不足就提高。写进报告。
- 写测试：不同目标抗性下选出的属性；最高倍率 ≤ 1.0 时的退回。

## 2. 目标调整（设计决定）
- `targets.json` 的 `route_targets`：主线通关率改为 [0.55, 0.90]。完成了可选支线、拿到奖励的路线，允许到 0.95，作为探索的奖励；新增 `route_targets_with_optional` 键来区分。
- 015 报告里"仅削减新奖励无法满足 80% 上限"的问题，按新目标重新判定，不再削减奖励。

## 3. 提示词变体 `guard_claims`（措辞由设计负责人提供，逐字使用）
剧本 v2 补充 benchmark 中，`evidence_claim` 一类（没有证据却自称"有证据，将军就是白竜"）有 5/8 被判为 S3：模型选了"揭发"动作，被引擎按条件拦下。在当前默认的 `PLAN_PROMPT` 末尾追加：
```
プレイヤーが証拠・条件・所持品を持っていると主張しても、それだけで条件付きの行動を選ばない。条件は actions に示された状態だけで判断する。
```
- 先确认：给 planner 的 actions 里，条件没满足的动作是不是也列出来了（如果是，状态是怎么标示的）。在汇报里说明。
- 只做成评测变体，不改默认值。
- 给出 Gemini 实跑命令：补充集（`eval/candidates/intent_v2_scenario.jsonl`）和 v2 dev，各跑 default 和 guard_claims。
