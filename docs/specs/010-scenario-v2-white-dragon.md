## 1. 引擎
1. **多阶段敌人**：敌人可以声明 `next_phase: "<enemy_id>"` 和 `phase_transition_text`。HP 归零时不算击败，换成下一阶段的敌人（HP 回满、状态清空），把转换文写进战斗日志，战斗继续。只有最后一个阶段被击败才算胜利。玩家的资源和状态不变。战斗 UI 能显示新敌人的名字和图像（图像先用占位，`TODO(design)`）。写测试。
2. **条件计数**：动作的 requirements 支持"下列 flag 中至少 N 个"，例如 `{"flags_count_gte": {"flags": [...], "count": 2}}`，并且能和 `has_item` 一起放进 `any` 里组合。写测试。
3. **观察揭示**：自由行动的 `observe` 作用在地点的 `objects` 上时，对象可以声明 `observe_reveals`：`{"roll": {"dice_type": "1d20+wis", "dc": 16}, "once": "<flag>", "success_effects": [...], "failure_effects": [...], "success_text": "...", "failure_text": "..."}`。判定由 Host 掷骰，结果由引擎发放，模型的叙述不能宣称发现。现在的观察已有"提示可见性质"的逻辑，在它上面扩展；没有 `observe_reveals` 的对象，行为保持不变。写测试，至少覆盖成功、失败、重复观察（once）三种情况。
4. 如果商店购买的现有实现不支持文档 4.7 的商品，按现有商店的方式补上。
