来源：用户试玩反馈（2026-10-13）。两份剧本（`dragon_rpg.json`、`dragon_rpg_hybrid.json`）始终同步修改。

## 1. 城下町ハブ（第 1 章）

现在从鍛冶屋、宿屋等处「城に戻る」会直接回到王の間，很怪。改为：王城和五个设施之间夹一个城下町节点。

- **新地点 `castle_town`**，标题「アルテリア城下町」，`scene_id` 沿用 `throne_room`。描述（叙事文本，照抄）：
  > 王城の門前から石畳の大通りが延びる城下町。鍛冶屋の煙突からは煙が上がり、宿屋の看板が風に揺れ、魔法店の窓には青い灯りがともる。裏手には細い路地が口を開けている。邪竜の噂のせいか、行き交う人々の声はどこか低い。
- **`castle_town` 的选项**（按此顺序）：鍛冶屋へ向かう / 宿屋へ向かう / 魔法店へ向かう / 道具屋へ向かう / 路地裏へ向かう / 行商人ガルドに声をかける（原 `ask_gald_rumor`，条件不变）/ 王城へ戻る（→ `castle`）/ **城門を出て闇の森へ向かう**（原 `go_dark_forest`，判定 DC10 不变，preview「第2章へ進みます」）。
  - 原来 `explore_castle_town` 下的 children 全部移到这里成为顶层选项，`explore_castle_town` 删除。
- **`castle` 的选项**：国王に邪竜の詳しい話を聞く / 将軍ドラコに助言を求める / 侍従から旅の支給品を受け取る（见第 2 节）/ **城下町へ出る**（新，→ `castle_town`，preview「王城の門前に広がる城下町へ」）。其余已有的条件选项（如 `return_village`）保持原样。
- **从 `castle` 和 `forge` 删除「城を出て闇の森へ向かう」**，出发只能从城下町的城门出发。
- 各设施的「城に戻る」改为「**城下町に戻る**」（preview「大通りへ戻る」）。现有分支逻辑保留：`returned_to_capital` 时仍去 `festival_town`，否则改去 `castle_town`。路地裏（含 `alley_after` 等）的返回也一样。

## 2. 支度金

现在开场国王给 50G + 薬草，「支度金と装備を確認する」又给 50G + 聖水 ×2。「确认」却拿到东西，不合理。

- 开场的国王改为给 **100G** + 薬草（所有提到 50 的开场文本和 prepared draft 同步改成 100）。
- `check_supplies` 改名为「**侍従から旅の支給品を受け取る**」，preview「教会から届いた聖水を受け取ります」，效果只给 聖水 ×2（去掉 50G），`once` 不变。result_text：
  > 侍従が小箱を差し出した。「教会より、邪竜討伐に向かわれる方へ」中には清められた聖水が二本収められている。
- 第 1 章拿到的总金币不变（100G），不影响平衡。

## 3. 选项可见性：玩家不知道的东西显示成「？？？」

问题：玩家还没出城，魔法店就有「泉の封印について尋ねる」；「虹晶の欠片を武器に仕立ててもらう」直接写出了还没见过的道具名。

### 3.1 规则（引擎计算，客户端显示）
沿用现有的 `visible_after` / `secret` / `hidden_after` 过滤之后，对**条件不满足**的选项按下面分三类：

| 类别 | 条件 | 显示 |
|---|---|---|
| 隐藏 | 不满足的条件里有 `character_id`（职业专属） | 不显示 |
| 已知但不够 | 不满足的条件全部是玩家知道的东西：金币、属性值、`lacks_item`，以及本局**曾经持有过**的道具（`has_item`，按 event_log 的 item_added 或当前背包判断） | 现状：显示标题和原因，不可选 |
| 未知 | 其余情况：flag 条件、从没持有过的道具、同伴条件等 | 标题「？？？」，不显示 preview 和 risk，原因「まだ知らない何かが必要なようだ。」，不可选 |

- 「未知」的选项在 public session 里**不能带原文**（标题、preview、条件文字都不下发），防止从网络响应里看到。
- 子选项同样适用；父选项的「N件」只数可见的子项（含「？？？」）。
- **planner 收到的 actions 不变**（这里只改玩家看到的）。如果你发现现有代码让两者共用同一份数据、不改会影响 planner，先停下来，在汇报里说明。
- 每种 requirement 类型归入哪一类，在汇报的推断清单里逐条列出。

### 3.2 剧本修正
- `ask_seal_lore`（魔法店「泉の封印について尋ねる」）：改为 `secret`，条件为 `any[flag mina_missing_heard, flag seen_cave_seal]`。进入 `cave_seal` 时设 `seen_cave_seal`（entry_effects）。
- 其余类似问题由第 3.3 节的报告找出，**不要自行修改**，交给设计负责人决定。

### 3.3 报告
`eval/reports/choice-visibility-2026-10-13.md`：列出第 1–2 章每个地点在玩家**第一次到达时**能看到的选项（标题、类别），以及选项文字里出现、但按最短路线到这里时玩家还没遇到的地名 / NPC 名 / 道具名（启发式即可，在报告里写明方法）。

## 4. 选项卡片变紧凑

现在每张卡片三行（标题、说明、标签），选项一多就要滚动很久。

- 卡片改为**单行**：编号、标题、右侧标签（risk 或「N件」）在同一行。卡片高度按现有字号和内边距收紧，800×480 视口下 6 个选项不滚动就能放下。
- 说明（preview）和条件文字平时不显示。选项面板底部加一条**固定高度的说明栏**，显示当前 hover、键盘焦点或高亮中的那张卡片的 preview；不可选的卡片显示原因。这样鼠标在卡片上移动时列表不会跳动。
- 触屏（`@media (hover: none)`）保持现状：说明照常显示在卡片里，不改成两次点击。
- 「？？？」卡片：虚线边框，文字用现有的禁用色，不显示标签。
- 颜色、字号、圆角只用现有 `styles.css` 里的变量和组件样式；不够用就留 `TODO(design)`，不要新挑颜色。

## 5. 开始画面

现在是星形徽记、「LOCAL TRPG」和一列下拉框，太简陋，而且「ローカルLLM」和「(Hybrid)」这种内部信息直接暴露给玩家。

- 背景：全屏 `bg_dragon_valley.png`，上浅下深的暗色渐变遮罩；缓慢放大（20 秒内 1.00→1.05，`prefers-reduced-motion` 时不动）。去掉星形徽记和放射状背景。
- 标题区：小字眉标「AI GM TRPG」（字距加宽），主标题用当前剧本的标题「紅き邪竜イグニス」（现有金色标题样式），副标题「AIのGMと紡ぐ、あなただけの冒険」。
- 角色选择：四张横排卡片（宽度 < 720px 时 2×2）：立绘（用游戏里该职业 / 性别现在用的那张，裁成半身）、职业名、一行描述、HP / MP。选中时用现有的金色边框和高亮。性别切换时立绘跟着换（只有有差分的职业才换）。
- 名字输入和性别放一行，下面是醒目的「冒険を始める」按钮。
- 剧本选择（Base / Hybrid / 狂気の館）和模型状态移进右下角齿轮的设置面板，默认 Hybrid。
